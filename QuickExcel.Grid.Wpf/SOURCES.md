# QuickExcel.Grid.Wpf source provenance

## Skia migration (2026-11-02)

The historical source inventory below describes the original import. The unused WriteableBitmapEx drawing/filter/glyph implementations, GDI+ font/bitmap path and direct `msvcrt.dll` imports have now been deleted. Only `IntGeometry.cs` and `PortableFontDesc.cs` remain from that embedded directory; both upstream licenses and the original import hashes are retained.

`HostRendering/SkiaBitmap.cs` is the WPF host pixel adapter: private locked Pbgra32 buffers, shared Skia text layout, bounded per-control metrics, overlap-safe managed span copies and WPF DPI discovery. `UseWindowsForms` is removed. The project references `QuickExcel.Rendering.Skia` (and transitively Core), but no Infrastructure or scripting code. Main workbook cells use `ExternalCellContent`, so the host's shared Skia cell pictures/rasters are the single content path; this control continues to paint headers and own geometry/input/selection. `CropBuffer` now copies source to destination in the correct direction. Fonts and shapers are released when the control unloads.

CPU completion observes grid, selection and host-content pending state at Render priority; it does not wait for Dispatcher idle or represent physical presentation. Optional timestamps support the benchmark evidence. Composition-driven drag scrolling deduplicates by frame, with a 50 ms occlusion fallback; the historical shared 16 ms wall-clock gate below has been replaced so the fallback cannot suppress a valid composition frame.

## Original import and earlier modifications

Imported on 2026-10-29 from [janproch/fastwpfgrid](https://github.com/janproch/fastwpfgrid/tree/8bcfaf37df343e0b7ccffb3718d9a973a1f58b40), commit `8bcfaf37df343e0b7ccffb3718d9a973a1f58b40`. `Upstream/` contains that tree's FastWpfGrid top-level C# and XAML sources. The MIT notice is retained verbatim in `FASTWPFGRID-LICENSE.txt` and copied to build/publish output.

`WriteableBitmapEx/` contains the **embedded, already modified** WriteableBitmapEx sources from the same FastWpfGrid commit, not a NuGet package or the current WriteableBitmapEx master. The embedded project does not declare a package release version; the immutable tree commit and per-file hashes are its version identity. Do not replace these sources with a nominally similar package without checking the added glyph, scrolling and geometry APIs.

Original source bytes, before local modifications, are identified by `UPSTREAM-SOURCES.json` (SHA-256). No upstream `.git`, legacy build output, test programs, assembly signing key, or old project metadata is included in the compiled project. Source downloads remain under QuickExcel `artifacts/sources` and are ignored by Git. Nothing is copied from the sibling ExcelIO repository.

WriteableBitmapEx copyright notices remain in source headers. Its MIT license was verified and copied from [reneschulte/WriteableBitmapEx](https://github.com/reneschulte/WriteableBitmapEx/blob/81eb25f52e2865069f6a5ca6ad3dfc1fd4f18c77/LICENSE), immutable commit `81eb25f52e2865069f6a5ca6ad3dfc1fd4f18c77`, into `WRITEABLEBITMAPEX-LICENSE.txt`. FastWpfGrid's added glyph/scroller files are covered by the containing MIT tree. Both license files ship with the desktop output.

Local modifications:

- SDK-style `net10.0-windows` WPF library; Windows desktop drawing support for the embedded glyph library, unsafe bitmap operations retained. No Core, Infrastructure, ExcelIO, scripting or network dependency.
- `GridCellRange` / `GridRangeSelection` replace per-cell selection sets, including Ctrl/Shift header selection, dragging, Select All, transposition and active-axis enumeration. Legacy explicit cell enumeration has a 100,000-cell guard.
- `FastGridControl_MergedCells.cs` accepts host-provided merge ranges and expands selection rectangles over intersecting merges. Selection and active-cell outlines use the same merged extent, including frozen/scrolling clips; current addresses resolve to the first visible cell of the merge. Expansion works on rectangles without enumerating covered cells.
- `SeriesSizes` precomputes visible-to-model mapping instead of scanning every hidden row on each cell read. Model intervals map by binary search in frozen/scrolling segments, including hidden endpoints; sparse dimension hit testing uses the actual scroll index and overridden size. Snapshot dimension replacement clears stale overrides after history changes.
- `SeriesSizes.ScrollInView` aligns an oversized row/column to its leading edge instead of scrolling past it. This allows imported XLSX columns wider than the viewport to remain selectable and visible; focused regression coverage is in `OversizedGridCellTests` and the desktop XLSX rendering smoke.
- Host geometry/range/dimension methods in `FastGridControl_Desktop.cs`; viewport notifications; frozen row/column intersection rendering fix; invalidation coalescing at Render priority.
- Explicit host dimensions survive first viewport creation instead of being replaced by text auto-fit; replacing the model resets that ownership flag. Dimension replacement recalculates header geometry from the current sheet, and viewport resize notifies the host's formatting layer.
- Bounded global font cache and per-font glyph caches; updated `FormattedText` overload, removal of an unused local and nullable annotation for the pure address type.
- Desktop disables the upstream inline model writer and view-only column resizing, and owns a native TextBox, snapshot projection, header buttons and controller commits. The upstream control's default DataTable adapter is not used by QuickExcel.
- Filtered/short-sheet hit testing and viewport counts stop at visible row/column bounds. Drag selection skips unchanged endpoints and repaints changed membership only. A private software canvas presents frozen viewport snapshots instead of sharing a mutable bitmap with the compositor; unchanged visible pixels reuse the previous frame. Diagonal auto-scroll updates both axes before selecting once. Desktop defers editor preparation until capture ends.
- QuickExcel opts into `GridSelectionOverlay` / `FastGridControl_Overlay.cs`: selection, current-cell outlines and row/header highlights use a retained WPF drawing layer, separate from content pixels. A current cell already in the selection shares its range outline instead of adding a nested or duplicate border. Each rectangular range intersects at most four frozen/scrolling viewport quadrants without cell enumeration. In-viewport dragging reuses the content frame and original text colors under translucent selection; bitmap selection remains the default for other hosts.
- `FastGridControl_RetainedContent.cs` caches immutable cell images produced by the original rasterizer, composes the viewport with a frozen `DrawingImage`, and prunes off-screen tiles. Large cells are cropped before allocation. `UseSmoothScrolling` is enabled by Desktop along with the overlay; other hosts retain the viewport bitmap path by default. Pixel offsets are shared by content, selection, hit testing and host geometry, with separate clips for frozen/scrolling quadrants.
- `FastGridControl_SmoothScroll.cs` replaces Desktop's 50 ms whole-cell auto-scroll with time-based pixel motion. WPF Rendering and a 16 ms occlusion fallback timer share one rate gate; movement is capped after dispatcher stalls. Capture loss/unload detach callbacks. Fast pointer exits select the visible edge immediately, even before the first scroll callback.
- `FastGridControl_RenderScale.cs` replaces the global window-DPI assumption with the control's measured scale to the compositor (ancestor layout transforms such as worksheet zoom multiplied by monitor DPI). The raster viewport, glyphs (`PortableFontDesc`/`GlyphFont` carry the scale), stored dimensions, hit testing, overlays and host geometry all use the same device ratio, and the bitmap is presented at its natural size instead of a rounded DIP width. A scale or DPI change rebuilds the buffer, glyph caches and retained tiles; `CropBuffer` preserves the device-density tag when resizing. Other hosts keep the previous behaviour by omitting the scale.

Desktop now uses this control as its main grid. Host transaction integration for drag resizing, style/merge/image decoration, viewport clipping and focused integration checks are recorded in [the main-grid migration](../QuickExcel.Desktop/docs/24-main-grid-migration.md). The host geometry API adds visible model axes, pane-clipped range fragments, DIP hit testing and default row height. Decoration is inserted below selection without introducing document dependencies into this library. The legacy global DPI detector, physical IME verification, complete complex-script rendering and automation peers remain separate quality gates. Original upstream hashes and licenses remain unchanged.
