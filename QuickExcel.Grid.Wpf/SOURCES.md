# QuickExcel.Grid.Wpf source provenance

Imported on 2026-10-29 from [janproch/fastwpfgrid](https://github.com/janproch/fastwpfgrid/tree/8bcfaf37df343e0b7ccffb3718d9a973a1f58b40), commit `8bcfaf37df343e0b7ccffb3718d9a973a1f58b40`. `Upstream/` contains that tree's FastWpfGrid top-level C# and XAML sources. The MIT notice is retained verbatim in `FASTWPFGRID-LICENSE.txt` and copied to build/publish output.

`WriteableBitmapEx/` contains the **embedded, already modified** WriteableBitmapEx sources from the same FastWpfGrid commit, not a NuGet package or the current WriteableBitmapEx master. The embedded project does not declare a package release version; the immutable tree commit and per-file hashes are its version identity. Do not replace these sources with a nominally similar package without checking the added glyph, scrolling and geometry APIs.

Original source bytes, before local modifications, are identified by `UPSTREAM-SOURCES.json` (SHA-256). No upstream `.git`, legacy build output, test programs, assembly signing key, or old project metadata is included in the compiled project. Source downloads remain under QuickExcel `artifacts/sources` and are ignored by Git. Nothing is copied from the sibling ExcelIO repository.

WriteableBitmapEx copyright notices remain in source headers. Its MIT license was verified and copied from [reneschulte/WriteableBitmapEx](https://github.com/reneschulte/WriteableBitmapEx/blob/81eb25f52e2865069f6a5ca6ad3dfc1fd4f18c77/LICENSE), immutable commit `81eb25f52e2865069f6a5ca6ad3dfc1fd4f18c77`, into `WRITEABLEBITMAPEX-LICENSE.txt`. FastWpfGrid's added glyph/scroller files are covered by the containing MIT tree. Both license files ship with the desktop output.

Local modifications:

- SDK-style `net10.0-windows` WPF library; Windows desktop drawing support for the embedded glyph library, unsafe bitmap operations retained. No Core, Infrastructure, ExcelIO, scripting or network dependency.
- `GridCellRange` / `GridRangeSelection` replace per-cell selection sets, including Ctrl/Shift header selection, dragging, Select All, transposition and active-axis enumeration. Legacy explicit cell enumeration has a 100,000-cell guard.
- `SeriesSizes` precomputes visible-to-model mapping instead of scanning every hidden row on each cell read. Model intervals map by binary search in frozen/scrolling segments, including hidden endpoints; sparse dimension hit testing uses the actual scroll index and overridden size. Snapshot dimension replacement clears stale overrides after history changes.
- Host geometry/range/dimension methods in `FastGridControl_Desktop.cs`; viewport notifications; frozen row/column intersection rendering fix; invalidation coalescing at Render priority.
- Bounded global font cache and per-font glyph caches; updated `FormattedText` overload, removal of an unused local and nullable annotation for the pure address type.
- Desktop disables the upstream inline model writer and view-only column resizing, and owns a native TextBox, snapshot projection, header buttons and controller commits. The upstream control's default DataTable adapter is not used by QuickExcel.
- Filtered/short-sheet hit testing and viewport counts stop at visible row/column bounds. Drag selection skips unchanged endpoints and repaints changed membership only. A private software canvas presents frozen viewport snapshots instead of sharing a mutable bitmap with the compositor; unchanged visible pixels reuse the previous frame. Diagonal auto-scroll updates both axes before selecting once. Desktop defers editor preparation until capture ends.
- QuickExcel opts into `GridSelectionOverlay` / `FastGridControl_Overlay.cs`: selection, current-cell outlines and row/header highlights use a retained WPF drawing layer, separate from content pixels. Each rectangular range intersects at most four frozen/scrolling viewport quadrants without cell enumeration. In-viewport dragging reuses the content frame and original text colors under translucent selection; bitmap selection remains the default for other hosts.
- `FastGridControl_RetainedContent.cs` caches immutable cell images produced by the original rasterizer, composes the viewport with a frozen `DrawingImage`, and prunes off-screen tiles. Large cells are cropped before allocation. `UseSmoothScrolling` is enabled by Desktop along with the overlay; other hosts retain the viewport bitmap path by default. Pixel offsets are shared by content, selection, hit testing and host geometry, with separate clips for frozen/scrolling quadrants.
- `FastGridControl_SmoothScroll.cs` replaces Desktop's 50 ms whole-cell auto-scroll with time-based pixel motion. WPF Rendering and a 16 ms occlusion fallback timer share one rate gate; movement is capped after dispatcher stalls. Capture loss/unload detach callbacks. Fast pointer exits select the visible edge immediately, even before the first scroll callback.

Known migration gaps are tracked in [the implementation record](../QuickExcel.Desktop/docs/23-fast-grid-implementation.md), particularly the legacy global DPI detector, complete font/complex-script rendering, host transaction integration for drag resizing, merged/image drawing and automation peers. This is an opt-in candidate, not a replacement for the production grid yet.
