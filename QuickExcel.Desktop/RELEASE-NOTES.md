# QuickExcel 0.4.0-preview.2 — 日期与时间显示修复

修复打开 XLSX 后日期、时间显示为 Excel 序列数的问题：表格按单元格数字格式显示，数值和公式缓存保持数值类型。

- 识别内置 14–22、45–47，以及简体中文约定的 27–36、50–58 日期/时间格式。
- 支持常见自定义年月日、中文文字、星期/月名、12/24 小时、分钟与月份区分、小数秒、[h]/[m]/[s] 累计时长，以及格式分段、条件和 locale 标记。
- 按工作簿的 1900/1904 日期系统显示，保留 1900 年虚构闰日。超出显示范围和负日期显示 ########。
- 未指定单元格样式时应用行/列样式；显式 General 格式保持普通数字。文字、布尔值和错误不会被猜测成日期。

# QuickExcel 0.4.0-preview.1 — M3 计算预览

在 0.3 类型化文件基础上增加跨工作表公式、名称绑定、标准公式增量求值和可移植公式导出。

- 支持转义/中文表名、绝对/相对/混合引用、矩形与整列、工作簿及工作表名称；类型和错误不会按字符串外观混淆。
- 通过工作簿依赖图完整计算，区分循环成员与受影响的下游；确定性公式只求值受影响闭包，TODAY/NOW 每轮更新。
- 行列插删/移动、跨表剪切和表改名已有可撤销命令；完整结构 UI、图片/合并锚点移动继续 M5。
- 增加 JS 函数描述符和命名空间，v2 参数桥显式提供二维范围；v1 扁平范围继续有效。

- 导出可选择“值快照”或“公式”：后者冻结脚本及跨表依赖结果，保留独立标准公式。冻结缺失结果会拒绝，旧结果需明确选择。
- XLSQ 保存当前缓存聚合状态与引擎标识，重开仍将缓存视为待重算，不恢复脚本授权。

本版继续 Windows x64 framework-dependent 发布，需要 .NET 10 Windows Desktop Runtime x64。完整支持矩阵、公式语义、版本选择和验收记录见 [M3 记录](docs/10-m3-calculation.md)；文件限制继续见 [M2 记录](docs/09-m2-files-and-types.md)。

不支持完整 Excel 语法/函数、外部工作簿、动态数组、3D/结构化引用和通配符查找。近似查找要求相应排序。拆分连续引用的结构移动、带图片/合并的结构移动会拒绝；不静默破坏数据。

进程内 QuickJS 仅供可信源码，没有独立 worker 或 OS 沙箱。M4 负责 worker 与动作，M5/M6 负责完整桌面、恢复和 Beta 收敛。干净机器、签名、安装器、原生干净重建及性能分位基准没有在本次完成。
