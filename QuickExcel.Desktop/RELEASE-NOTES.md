# QuickExcel 0.2.1 试用版

## 0.2.1 关闭窗口修复

修复未修改文档直接关闭、或选择“不保存”后，提示“在窗口关闭期间……无法调用 Close”的问题。确认和保存流程会等当前 Closing 事件返回后再执行；连续关闭请求不会重复进入，取消或保存失败仍保留可编辑文档。文档只在窗口真正关闭后释放，待关闭期间的排队自动重算不会访问已释放会话。

新增 8 类真实 WPF 窗口关闭回归：干净关闭、丢弃并阻止排队重算、取消后继续编辑、无效输入阻止关闭、保存后关闭、保存失败保留文档和原文件、忙碌时拒绝关闭、最终关闭被取消时保留会话；同时验证重复请求不重入。此前 smoke 绕过了真实 Closing 事件，未覆盖此次缺陷；本版已补齐。

## 0.2 交付范围

这是 Windows x64 的第一版可运行交付，范围为实施计划的 M1：统一文档会话、不可变稀疏快照、事务编辑和撤销/重做、计算结果代次校验、存储与运行时适配，以及桌面编辑和保存路径整合。它不是 M2–M6 全部完成后的 Beta。

## 启动

解压完整目录，运行 `QuickExcel.exe`。程序为 framework-dependent 发布，**需要已安装 .NET 10 Windows Desktop Runtime（x64）**；不包含 .NET Runtime。仅验证安装了相应运行时的开发环境，不宣称已通过干净机器安装验收。构建工具不是运行时必需组件。

可在程序内打开 `.xlsq` 或 `.xlsx`，也可将文件路径作为启动参数。点击“应用脚本并重算”前，工作簿中的 JavaScript 不会执行。

## 这一版可以做什么

- 编辑单元格和公式，通过公式栏输入；批量粘贴和清空以一个事务提交，失败不产生半批数据。
- 对单元格编辑和新增工作表执行撤销/重做；保存、脚本授权和计算缓存各自使用清晰的状态。源码编辑使用脚本编辑器自身的文本撤销。
- 单元格在内存中区分文本、数字、布尔、错误和空白；存储采用稀疏快照，编辑远端单元格不会先分配前方全部空格。
- 保存前提交仍在编辑的单元格与公式栏内容；无效编辑阻止保存。输入有效但重算失败时，允许保存输入和旧缓存并明确提示结果过期。成功保存才更新已保存修订，文件替换失败保留原文件。
- 保留原型已支持的公式源码、结果缓存、字体/填充/边框/对齐、行列尺寸、隐藏状态、合并区域和图片；界面显示能力仍是原型子集。
- 计算在快照上运行，过期代次、旧脚本或已关闭会话的结果不能覆盖新内容；桌面长操作期间暂时锁定编辑。
- 任意脚本编辑立即撤销执行授权，校验失败的编辑也不会继续沿用旧授权；启用或停用脚本本身不改变已保存修订。

## 已知限制

- **仍使用 XLSQ formatVersion 1。** 字面量保存及导出为文本，重新打开不猜测恢复已丢失的数字、布尔和错误类型。空白与空文本可能合并。公式结果作为缓存重新载入，不代表结果仍然有效；稳定身份和修订属于当前会话，不写入 v1 文件。
- `.xlsx` 导出是当前结果导出：公式转换为缓存值，不带脚本。尚未实现 M2 的完整类型/日期往返、未知部件保真和安全保留机制；复杂 Excel 文件不属于完整兼容承诺。
- 跨工作表公式及其依赖暂不计算，保留缓存并显示诊断。公式重算仍是兼容计算器，没有 M3 的完整增量计算、结构引用变换或 Excel 函数覆盖。
- QuickJS 在应用进程内运行，只有内存/栈/执行时间限制，尚无独立 worker 或操作系统沙箱。**只启用你信任的工作簿脚本。** 不支持异步、Promise 或对象公式结果。
- 界面最多显示/编辑 100,000 行、256 列，单次粘贴最多 20,000 格；领域最多 64 张表、每表 1,024 列、总计 1,000,000 个存储格。旧版 IO 适配的占位行或单元格另有 1,000,000 个预算，跨度过大的稀疏数据保存时会明确拒绝。
- 撤销历史默认预算 32 MiB；超过预算时释放最早记录并在界面提示。单个操作超过预算会在提交前拒绝。
- 暂无 M5 的完整排序/筛选/冻结、合并编辑、图片编辑、无障碍专题和 IME 全场景验收；也未完成 M6 的独立安装包、签名、自动更新与干净机器矩阵。

## 验证与来源

每个发布包携带 `BUILD-METADATA.json`，记录实际构建配置、Git HEAD 与工作树是否有未提交改动、SDK/运行时、原生 DLL SHA-256，以及本次脚本实际运行的单元测试、原生 smoke、WPF smoke 状态。源码验证结果应以该包记录和仓库实施记录为准。本次实现仍是未提交工作树，metadata 中的 HEAD 与 dirty 必须一起理解；HEAD 单独不代表全部构建源码。

发布 ZIP 使用版本、UTC 时间和随机后缀命名，旁边提供 `.sha256` 文件。包内不包含 smoke 工作簿、截图、运行日志或已有输出目录中的用户文件。
