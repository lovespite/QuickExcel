# QuickExcel 0.3.0-preview.1

本次交付 M2 文件阶段的可试用版本。源码从 QuickExcel `82381fe` 继续实现；本轮修改尚未提交。0.2.1 的历史发布证据保留在实施记录中。

## 新增

- XLSQ v2 manifest、SHA-256 条目摘要、稳定文档/表身份、修订和脚本模块绑定。
- 类型化、稀疏 XLSX 读写；保留数字、布尔、错误、文本前导零、空文本与空白。公式与类型化缓存分开保存，重开缓存按待重算处理。
- 1900/1904 日期系统、原始日期序列、内置/自定义数字格式、基础样式、行列元数据、合并和受支持的浮动图片。
- v1 迁移另存、未知部件/属性报告、未编辑 XLSX 原字节保留，以及明确选择的受支持副本。
- ZIP 中央目录与展开预算、XML/JSON 深度及重复字段检查、规范关系解析、取消入口。
- 写入临时文件后重新读取并核对类型、结构、身份、修订和脚本摘要，再原子替换。
- 桌面接入 v2 保存、迁移说明与旧缓存/损失选择；WPF smoke 增加真实类型保存和迁移流程。

## 兼容性与边界

v2 文件不能由 0.2 的 v1 读取器打开。迁移不覆盖 v1 原件，也不把旧文件中的文本猜回数字。回退旧程序时使用保留的 v1 原件或另行导出的 XLSX。

完整主题/富文本/命名样式、数组与结构化共享公式、复杂绘图、单元格内图片、图表、透视表等不属于本版可编辑保真承诺。能够读取的未建模内容会报告并保护；无法可靠解释的单元格/公式结构直接拒绝。取消保存不更换已有文件。另存受支持副本会移除报告中的内容；建议重新打开副本继续工作。

XLSX 导出不含脚本，全部公式转为值；缺失结果不能导出，过期结果需明确选择。宿主 `#SCRIPT!` / `#CYCLE!` 在 XLSQ 中保留身份，在 XLSX 值快照中映射为标准 `#VALUE!`。

多模块可以读取和保存，但当前运行时拒绝执行。单模块源码仍仅限可信脚本；本版没有独立 worker、OS 沙箱、自动恢复或完整 Excel 计算兼容。日期显示/函数与跨表增量计算留待后续。

发布为 Windows x64 framework-dependent，需 .NET 10 Windows Desktop Runtime。无 SDK 干净机器、原生干净重建、签名及安装器验收未在本次完成。

实际验证日志、支持矩阵和产物路径见 [M2 记录](docs/09-m2-files-and-types.md)。
