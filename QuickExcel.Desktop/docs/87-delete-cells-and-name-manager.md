# 删除单元格与名称管理器

版本：5.1.0；日期：2026-11-20。

## 删除操作

- 行列标题右键与功能区的“删除行”“删除列”立即执行，不再询问确认；仍可一次撤销。
- 普通连续矩形选区通过右键、编辑菜单或开始功能区的“删除单元格…”打开四选一对话框：右侧单元格左移、下方单元格上移、整行、整列，默认左移。完整行列选区直接删除相应行列。
- 左移/上移通过 `DeleteCellsCommand` 提交，更新受影响的单元格、公式和名称引用；整个操作只有一条历史记录。被完整删除的引用变为 `#REF!`，可保持矩形的范围引用随之收缩。
- `Delete` 键和“清除内容”继续只清除内容。取消删除对话框不修改工作簿；对话框打开后文档或选区改变时拒绝旧操作。
- 保留结构操作的附件保护：不能安全映射的链接、批注、线程评论、表格、验证、条件格式、图表源、打印引用、筛选隐藏行、数组溢出和非连续引用会拒绝整次操作。不会静默丢弃附件或拆分范围。可安全移动的合并区域、富文本和忽略错误元数据随单元格保留。

## 名称管理

- 公式功能区、编辑菜单和选区右键可打开“名称管理器”；列表显示名称、数值预览、引用位置、作用域与批注，集中完成新建、编辑、删除和筛选。
- 右键“创建命名区域…”直接打开新建对话框，预填当前选区的绝对引用。可选工作簿或工作表作用域，填写批注；编辑已有名称保留作用域。
- 名称和批注保存至 XLSX/XLSQ，重新打开后保留。新建、编辑、删除均使用文档事务并支持撤销；同一作用域中的重名不覆盖已有名称。
- 数值预览只使用可读取的当前结果，复杂公式或旧结果不冒充新计算值。
- 命名区域沿用脚本对象 API，无需新增权限或执行路径。例如工作簿作用域名称 `ELN`：

```javascript
const range = workbook.getNamedItem("ELN").getRange();
const values = range.getValues();
```

工作表作用域名称通过相应工作表读取：

```javascript
const range = workbook.getWorksheet("配额表").getNamedItem("ELN").getRange();
```

名称脚本句柄使用会话内稳定身份，删除后重新创建同名区域不会使旧句柄指向新对象。
