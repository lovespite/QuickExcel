# XC-0204：工作表复制、顺序与名称管理

2026-10-30 完成声明范围。新增工作表复制、左右重排和名称管理入口，复用既有新增/删除/改名与 DocumentSession 历史。R/D/C/E/W 使用现有 XLSX/XLSQ 名称和工作表模型，没有新增容器版本或脚本权限。

## 工作表与事务

插入菜单和工作表右键菜单可复制当前表，输入新名称后插入当前表之后；左右移动跨过隐藏标签，保留活动表的稳定 SheetId。复制获得新 SheetId，单元格、有效样式引用、富文本、行列尺寸、合并、图片、视图、打印设置及可见性一起复制，公式缓存重新计算。复制后的可见表自动激活；复制/重排/撤销/重做的模型活动表与界面标签一致。

公式通过 AST 变换：显式指向源表的引用改指副本，其他工作表引用、字符串和相对坐标保持。复制所有源表局部名称，同时复制依赖源表的全局名称及其传递闭包到副本局部作用域；与源表局部名称同名的全局项不覆盖它。复制的名称定义显式限定其已复制依赖，未被复制的全局依赖仍保持全局绑定。未使用但依赖源表的全局名称也在复制范围内。

命令在不可变快照上准备，容量/重名/引用检查失败不写入历史；每个操作一次撤销。沿用最多 64 表、总单元格和名称数量预算。不提供跨工作簿复制。含链接/批注的工作簿尚未实现附件引用变换，复制及名称改名继续明确拒绝；重排不变换附件地址。导入未知函数（包括未被单元格引用的名称定义）不能绕过结构变换保护，只读公式工作簿仍不可修改。

## 名称管理

对话框列出名称、工作簿/工作表作用域，支持创建、改名、替换定义及删除。既有名称的作用域固定；改名和定义替换作为一个事务提交。支持中文名称，拒绝单元格地址、R/C、R1C1、空白及既有无效名称。定义继续要求带表名的绝对单元格/区域引用；常量和已支持表达式可用，相对名称不在范围内。

单元格公式中的裸名称优先匹配当前表局部名称，再回退全局名称；名称定义中的裸名称匹配全局名称。显式 `Sheet!Name` 先查该表局部名称，再回退全局项。改名根据修改前的绑定重写单元格和其他定义，只修改实际引用该名称的 AST 节点；字符串不变。若新名称已在其他作用域存在，保守拒绝以免捕获已有引用。

删除全局名称保留公式文本，计算呈现名称错误，撤销恢复结果。删除局部名称时，若仍有显式 `Sheet!Name` 引用，Excel 会生成当前模型不支持的工作簿限定名称，因此明确拒绝且无部分历史；未限定引用按剩余名称重新绑定。只读文件可查看对话框，编辑按钮禁用。IME 组合与原地址草稿仍经过既有门禁。

## Excel 对照发现

本机 Excel 16.0 build 20527（x64，语言 2052，EXE 16.0.20527.20088），自有隐藏 COM 实例，宏禁用、外链不刷新，仅操作隔离夹具。

真实 Excel 揭示两个需要实现修正的行为：名称定义中的裸 `Rate` 不受调用单元格所在表的局部 `Rate` 遮蔽；复制后若把同名全局/局部名称分散追加到 XML，Excel 会将部分引用错误绑定到全局项。本项按名称分组、局部作用域置前写出，修复复制公式结果 40/50 的差异。仅去掉工作表引号并不能修复该差异。名称集合的存储回归改为比较名称/作用域/定义，不再把 XML 排列顺序作为内容身份。

Excel 在第一次保存复制表时会将部分名称别名显式限定。本工具保留第一次保存前、首次重开和再次保存重开三个状态，以首次重开作为规范化预期；只接受 AST 等价的括号等公式表示差异。采集可见用户名称，不把 COM 临时隐藏名称 `_xlfn.SINGLE` 当作文件名称模型支持。
