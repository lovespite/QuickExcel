## 支持矩阵

| 内容 | 0.3 行为 |
| --- | --- |
| 数值、布尔、标准错误、文本 ID | 直接采用 XLSX 类型；禁止按字符串外观猜型 |
| Blank / 空文本 / 缺失公式缓存 | 分别保存；无结果导出失败 |
| 标准公式、同工作表共享公式 | 保留/展开为独立公式；转换引用时保护引号内文本、绝对/混合引用 |
| 数组公式、外部/结构化共享公式 | 拒绝可编辑导入，不返回半个文档 |
| 日期 | 保存有限数字序列、日期系统和数字格式；不经 DateTime 归一化；没有承诺完整日期显示 |
| 字体、实色填充、四边边框、基础对齐 | 模型覆盖范围往返；主题、继承/命名样式和未支持属性进入损失报告 |
| 行高、列宽、隐藏、合并、网格线、标签色 | 支持；不支持的视图和页面设置进入报告 |
| 浮动图片 | 无像素偏移的 twoCellAnchor 支持 PNG/JPG/GIF/BMP/TIFF；复杂锚点/旋转/裁剪进入报告 |
| 单元格内图片/复杂绘图 | 原包可不变保留；不提供编辑保真或静默转换 |
| 未建模部件/属性/外部关系 | 不访问外部地址；原 XLSX 字节可不变保留；工作簿修改后要求明确损失选择 |
| 多模块/绑定/可选 JSON 属性 | 源码与元数据保留；模块不执行；操作脚本 requiredFeatures 明确拒绝 |
| 脚本缓存 | 不从磁盘恢复执行授权，也不因 manifest 声称 fresh 就信任缓存 |
| XLSX 导出 | 类型化值快照；旧缓存需明确选择，缺失缓存拒绝；宿主错误映射标准错误并提示 |

支持的边界是读写能力，不是计算能力。普通公式和跨表公式仍可能被 M1 计算适配标记 Blocked；M3 才完成跨表与增量计算。

## 容量及失败行为

- 输入/单个条目/输出上限 64 MiB；嵌套包累计展开量 256 MiB。
- 中央目录先校验数量和大小；不支持 ZIP64、分卷、加密或非 Stored/Deflate 压缩。包路径不接受目录条目、反斜线、越界、百分号编码别名或大小写歧义。
- 外层最多 72 条、内嵌 XLSX 最多 2048 条；manifest 64 KiB，state 1 MiB，所有源码合计 1 MiB；最多 64 模块。
- XML 深度 64，JSON 深度 32，解析累计计费预算 256 MiB；这是解析/对象计费上限，不是已经实测的进程 RSS 上限。写出预检也计入单元格、文本、元数据和图片。
- 模型上限仍为 64 表、每表 100,000 行/1,024 列、全簿 1,000,000 存储格；还须同时满足解析/写出预算。远端空洞不展开。
- 样式最多 4096，兼容性问题去重后最多 1024 类，图片累计最多 64 MiB。
- XML DTD/外部实体禁用；所有内部关系必须存在且无环。取消或校验失败不发布部分快照。
- 另存副本后保留原会话中的导入来源，后续仍可能显示原兼容报告；重新打开副本可刷新来源信息。
- 外部文件冲突检测、磁盘故障/断电恢复及自动保存留待 M6，不以原子替换冒充恢复机制。
