# M5 正式界面与桌面流程

2026-10-28，`0.6.0-preview.3`。本轮将已验证的 M5 原型迁入正式产品界面，继续实现 JS-011、FMT-009、UI-006–008。版本仍为候选；本记录不把实现或合成输入等同于整个 M5/M6 验收通过。

## 界面与启动

- 无文件参数时进入开始页：空白工作簿、打开、最近文件、示例、打开恢复副本。示例不再自动载入。命令行文件参数直接打开；失败保持当前文档/开始页。
- 主界面由紧凑命令栏、公式栏、网格、工作表标签及状态栏构成。说明放在提示、兼容报告和文档中，不常驻原型宣传/教程。
- 工作表标签使用展开的单选列表，默认底部横向滚动；设置支持左/右侧纵向滚动，文字始终水平。切表沿用原有提交、IME 门禁及稳定 SheetId。多表滚动保留选择可见。
- 设置保存在 `%LOCALAPPDATA%/QuickExcel/settings.json`，支持 75–175% 网格缩放；无效 JSON、枚举或范围回退默认值。写入使用临时文件替换，失败不阻止编辑。验证使用独立目录。
- 开始页保留当前工作簿，返回无需重开；关闭工作簿经过保存/放弃/取消后回到开始页。没有增加自动运行脚本或降级 worker 的入口。

## 脚本专页（JS-011）

“脚本”切换到独立编辑页面：左侧模块，右侧源码，下方问题/输出、动作列表及行列位置。源代码仍由原有 session 命令提交，修改立即撤销运行授权，非法草稿阻止切模块/文件/页面。不同模块的文本撤销缓冲不混用；运行、停用和状态栏停止使用原有独立 worker。

新建工作簿使用 API v2；打开的 v1 不自动升级。API v2 可添加库模块，指定公式/操作/两者用途；至少保留一个入口。导入仍只能使用清单中的逻辑 ID。v1 的模块用途只读，保留原脚本语义。模块 ID、路径和总量仍由领域模型验证。

问题列表有界（最多 200 项），包含运行诊断和公式错误。双击/Enter 可定位单元格；源码诊断有行号时定位对应模块和行，没有行号时明确提示。日志保留原有 12,000 字符上限。旧结果数量在主状态栏显示。

本轮补通原生桥与 worker 的错误诊断：保留模块逻辑 ID 和行号；原生文本上限 16 KiB UTF-8，再按现有协议日志预算截断。桥接在加载源码前保存引擎原生 Error stack getter，诊断时直接调用，避免执行用户覆盖的 `stack` getter。QuickJS-NG 版本/哈希/许可证及 worker 隔离策略不变。

## 查找与替换（UI-007）

Ctrl+F/H 打开同一窗口。范围可选当前表/整个工作簿/打开对话框时的精确选区；对象可选显示值/公式源码，另有大小写、整格匹配、包含隐藏行列。默认排除显式隐藏及筛选隐藏目标。不连续选区按实际地址搜索，查找结果按表、行、列排序；最多 20,000 格，超限要求缩小范围。

全部替换先生成并验证完整 patch，经 `EditorController` 和 `SetCellsCommand` 一次提交/一次撤销。分配结果字符串前检查重复替换的膨胀长度，超过单元格容量整批拒绝。显示值匹配公式结果时整批拒绝，避免把公式悄悄覆盖为文本；改用公式源码可修改公式，并验证替换后的语法。文本保持文本身份，即使结果以 `=` 开头；其他值不允许通过替换隐式创建公式。查找不改文档，关闭窗口不执行替换。原有不连续复制/矩阵粘贴拒绝规则保持。

Ctrl+G 定位 A–IV、1–100000 范围；隐藏目标提示先显示，不静默更改筛选。F6 在网格/公式栏/工作表标签间切换；脚本页在模块/源码间切换，Ctrl+Tab 离开接受 Tab 的源码编辑器，Ctrl+PageUp/Down 切表。

## 图片、合并与结构（UI-008）

`SheetArtworkAdorner` 是只读呈现层，在实际虚拟化行坐标上绘制基础图片和合并区域，横向冻结拆分裁剪；顶部只读冻结参照区有自己的投影。两层分别位于网格内的 `AdornerDecorator`，随页面/停靠/缩放一起布局；比较几何后才使绘制失效，避免无条件 LayoutUpdated 重绘循环。图片采用内嵌字节，不解析外部 URL；预览检查 1600 万像素预算并限宽解码到 2048 像素，超限/解码失败显示占位，保存原始字节。动画格式显示首帧。复杂原文件锚点仍以存储兼容报告为准。

合并显示左上角内容，编辑定位主格；新建合并拒绝遮盖其他非空内容、公式及重叠区域。取消合并不修改原单元格内容。写入非主格的非空内容使整批事务失败；清空仍保留样式。基础样式随内容显示，未宣称完整 Excel 排版。

行列插入/删除/移动会同步变换支持的矩形合并区及图片锚点，事务/撤销包含完整几何。内部插入扩展范围，全部删除移除对象；部分删除合并主格、拆分合并区/图片、越界或合并重叠均拒绝。任意单元格块移动和排序对有图片/合并的表仍明确拒绝，避免不支持语义的无提示破坏。

## 兼容、导出和恢复原型（FMT-009 / UI-006）

文件菜单提供独立兼容报告与导出选择：值快照、可移植公式两种模式。沿用既有具体损失列表、过期结果确认、缺失结果拒绝及迁移另存。取消不输出文件，不改变脚本授权。

开始页可打开用户选择的恢复 `.xlsq` 副本，取消原路径绑定，停用脚本，再保存必须另存。**没有自动恢复写入器或自动恢复发现**；30 秒自动保存、崩溃恢复选择器、持久化故障矩阵属 M6/FMT-010，不能称已完成。

主要控件提供 UI Automation 名称，焦点可见，网格采用 WPF 布局缩放。读屏实机、更多输入法及跨 DPI 矩阵仍需逐项记录，不由名称断言代替。

## 验证

- `M5ProductTests` 覆盖跨表/不连续/隐藏策略、原子替换、类型保留、公式拒绝/验证、容量、合并/图片结构变换及设置损坏恢复。
- `--product-smoke` / `test-m5-grid.ps1 -Mode Product` 验证实际 WPF 页面、控件、查找窗口、模块、布局缩放和存储，并生成逐项 JSON 与开始页/主表/侧栏/脚本/缩放/冻结截图。像素断言核对合并背景跨格、内嵌图片、左右侧导航切换后的显示及冻结合并层，不能仅以 renderer 非空判定呈现通过。
- 完整 smoke 保留 close/storage/calculation/date/worker/actions/interaction/workspace 回归，并新增 product 子结果。测试不使用测试 fixture 发布为产品功能。
- `--ui-validation <目录>` 仅隔离手工实机验收的设置和最近文件；不启用自动脚本、不注入对话框决定。
