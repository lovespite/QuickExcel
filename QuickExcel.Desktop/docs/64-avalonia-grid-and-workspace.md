## 绘制、生命周期和预算

视口几何使用 Grid.Shared 的 SeriesSizes/ViewportAxis；隐藏坐标通过模型区间二分查找相邻可见格，不跳回视口首格。冻结/滚动片段复用同一合并逻辑范围。只遍历可见轴；多范围和全选保持矩形列表。图片/图表锚点由共享 DrawingGeometry 投影。

单元格 picture 与整视口不可变 raster 分开；选区、引用、填充预览独立绘制。上屏使用物理像素源矩形；DIP、系统缩放和工作表缩放分别处理。缓存最多 4,096 个 picture/32 MiB，图片 64 MiB，视口 16,000,000 像素；单个 picture 超预算拒绝。文档/工作表切换、卸载、Dispose 和绘制失败释放拥有的资源。绘制失败可见提示，后续有效失效可重试。

自动化对象数不随工作簿存储格或选区面积增长。值提供者写入的是原生草稿，提交仍经过异步 EditorController；不能通过辅助接口绕过保护或验证。对照的 Avalonia 公共接口来源为 [12.1.4 ControlAutomationPeer](https://github.com/AvaloniaUI/Avalonia/blob/12.1.4/src/Avalonia.Controls/Automation/Peers/ControlAutomationPeer.cs) 与 [IValueProvider](https://github.com/AvaloniaUI/Avalonia/blob/12.1.4/src/Avalonia.Controls/Automation/Provider/IValueProvider.cs)。
