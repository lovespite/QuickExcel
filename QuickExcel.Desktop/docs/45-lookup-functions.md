# XC-0206：查找公式与 XLSX 函数别名

2026-10-30 完成声明范围。完善 VLOOKUP/MATCH，增加 HLOOKUP、XLOOKUP、XMATCH，接入计算、补全、参数提示和保留公式保存。仅实现标量查找及返回，不提前开放动态数组。

## 支持模式

| 函数 | 支持与边界 |
| --- | --- |
| VLOOKUP / HLOOKUP | 矩形表、正数返回索引（小数截断）、精确或已排序近似查找；精确文本支持 `* / ? / ~`，近似升序重复键取最后一项 |
| MATCH | 单行或单列；0 精确、正数升序近似、负数降序近似；升序重复键取最后一项，降序取第一项 |
| XLOOKUP | 查找与返回区域均为同形单行/单列；可指定标量未找到结果，按需计算；返回格和未找到结果的真空白变为数字 0，空文本保留 |
| XMATCH | 单行或单列，返回一基位置 |
| 现代查找模式 | match_mode 为 0（精确）、-1（精确或次小）、1（精确或次大）、2（通配符）；search_mode 为 1（从首项）或 -1（从末项）；模式须是常量，省略参数可留空 |

范围支持直接引用、跨表及绑定后的名称。现代近似模式可处理未排序向量；相同候选值按搜索方向取首次出现。传统近似模式要求输入按声明方向排序，未排序数据的 Excel 行为不在支持承诺中。

数字、数字外观文本、布尔、真空白和空文本分别匹配；候选错误跳过，查找值错误或选中的返回错误传播。传统函数的空查找值按 0，现代函数保留空白身份。现代模式的小数向下取整（例如 -0.5 是 -1），MATCH 则只取符号，V/H 的 range_lookup 使用布尔转换。传统文本查找值超过 255 字符给出 `#VALUE!`；现代函数支持更长文本，通配符采用可取消的有界内存匹配。查找转义与条件统计不同：`~` 消耗后一个字符，末尾单独 `~` 被消耗；真实 Excel 样本固定该行为。

文本比较采用 invariant 大小写无关规则，通配符按 UTF-16 字符匹配；不承诺所有地区的排序和 Unicode 特殊字符与每种 Excel 区域设置完全相同。全列按 Excel 的 1,048,576 行计算位置，只遍历已存单元格并补首/末空白位置，不扩大可存网格容量。

二分搜索 ±2、正则模式 3、计算得到的现代模式、多格返回/查找值和多格 fallback 尚未实现。绑定时明确拒绝；文件导入进入整簿只读、旧缓存 Blocked、原包保存路径。非法常量参数仍返回普通公式错误，不误判为新增数组能力。INDEX 等计算引用不在查找范围参数的首期范围。

## 文件与编辑

仅 XLOOKUP/XMATCH 的已实现 `_xlfn.` 别名在词法层归一化；普通源码大小写、空白、引号内文本和表名保持。写 XLSX 单元格和名称定义时补回标准前缀。未知扩展函数继续作为不透明未知函数，不剥除前缀，不执行脚本替代；内置登记也拒绝脚本伪装这些别名。名称没有变化时保留原不可变数组，避免无意义的结构变化。

显式省略参数仅扩展到现代查找允许的位置，其他函数原有语法约束不放宽。保留 DocumentSession 的单次撤销、增量重算和计算预算。依赖图仍保守包含 fallback 引用；懒求值不消除静态循环/脚本依赖限制。
