## 网格边界

`IGridSurface` 提供绑定快照、刷新、读取选区、定位/扩展选择、开始/提交/取消编辑。`WpfGridSurface` 是当前适配器，不接受领域写入；所有变更继续经 `EditorController`、`DocumentSession` 预检、事务与历史。

`VirtualRowList` 使用 IList 索引访问与稳定行身份，首次访问才建立行对象。没有为每个空单元格分配对象；曾访问的行对象保留至切换工作表/重建行集合，最坏仍可达到界面 100,000 行，不声称无限常量内存。DataGrid 保持双向控件虚拟化与 Recycling；只有正在呈现的 DataGridRow 收到刷新通知，滚动时从当前不可变快照读取显示值。显示值与编辑用原始值/公式保持分离，日期显示沿用 M3 格式器。

当前界面上限仍为 100,000 行 × 256 列，超出列数的数据不因不可见而删除。`＋行/列` 扩展显示范围。列宽、隐藏、已有基础颜色/粗体沿用原实现；本切片没有新增样式编辑。

## 编辑、焦点与选择规则

| 操作 | 规则 |
| --- | --- |
| 首次单击未选中单元格 | 仅选中，显示计算/格式化结果和绿色单元格边框，不显示文字选区或光标，不产生草稿 |
| 再次单击当前单元格 / 拖动 | 保持选择语义，可从已选中格拖出矩形；多格选区中单击当前格缩为单格；Shift/Ctrl 点击保留选择语义 |
| 双击 / F2 | 进入编辑并显示原始输入；F2 将插入点放在末尾 |
| Enter / Shift+Enter | 提交当前有效输入，向下/上移动一行 |
| Tab / Shift+Tab | 提交并向右/左移动；显示范围的列边界换行 |
| Escape | 取消当前 grid 或公式栏草稿，不产生文档事务 |
| 方向键 | 非编辑态移动；文本编辑态由 TextBox 操作光标 |
| Shift+方向键 | 从锚点扩展连续矩形；键盘扩展上限 20,000 格 |
| Home / End | 当前行第一列/已使用末列；Ctrl 同时到第一行/已使用末行 |
| Ctrl+方向键 | 到显示范围内对应已使用边缘；不承诺 Excel 的连续数据块跳转语义 |
| Ctrl+A | 选择显示范围内已使用矩形；超过 20,000 格则明确拒绝 |
| Ctrl+Z/Y | 文本编辑时使用当前 TextBox 文本历史；退出编辑后使用工作簿命令历史 |
| 保存/切表/打开/关闭 | 继续共用提交入口；非法输入保留草稿与原地址，阻止后续操作 |

没有正在输入的草稿时才执行排队重算，避免切换编辑器时后台刷新覆盖草稿。公式栏草稿固定在开始编辑时的地址；网格与公式栏切换遵循旧输入先提交、新输入后提交的顺序。运行计算时工作区仍禁用，结束后恢复仍连接到窗口的输入控件焦点，本切片不开放并发编辑。加载文档后同步复位选框、当前编辑地址和公式栏，即使重开的是相同工作表身份。

焦点进入单元格时预先准备原生文本编辑控件，使首个 IME 按键到来前已具备输入上下文。此“就绪”状态仍显示计算/格式化结果，不产生草稿或文档事务；控件隐藏光标、文字选区和编辑边框，并让鼠标命中单元格，保留网格选择入口。再次按下已选中格时退出就绪编辑器、释放其键盘焦点，让 DataGrid 接管鼠标捕获和拖选。直接键入替换显示文本并恢复编辑外观，F2/双击再载入原始输入。原始输入在控件生成时初始化，不能在 PreparingCellForEdit 中覆盖 WPF 已转发的首字符。程序刷新公式栏或网格编辑文本时清空对应文本撤销栈，Ctrl+Z 不得恢复其他单元格/旧工作簿的显示内容。

IME 的 PreviewTextInputStart/Update 开启提交门禁，PreviewTextInput 的路由处理结束后才解除。组合期间不截获候选确认的 Enter/Tab/Escape；点击其他编辑器、工具栏或切表入口会保留组合焦点并提示先完成/取消，防止 Windows 失焦时提交未完成的拼音。保存不会落盘半成品。本机拼音的空格选择中文候选，Enter 接受当前拼音原文；两者均不提前移动单元格，组合结束后再 Enter 才提交并下移。

## 剪贴板契约

- Ctrl+C 复制显示结果，不含脚本、样式或公式源码。必须是连续矩形；非连续选区明确拒绝，不再复制其包围矩形内未选中的数据。最多 100,000 格、4 Mi 个 UTF-16 字符。
- Ctrl+V 按数字/布尔/文本输入规则粘贴，`=` 开头的内容强制保留文本；`00123` 保留文本。Ctrl+Shift+V 显式允许把 `=` 开头内容解析为公式。均不自动授权脚本。
- 前导单引号从剪贴板按数据保留；手工编辑的前导单引号仍是强制文本语法。
- TSV 支持双引号、转义双引号、字段内 Tab/换行、空字段和尾部行终止符；不规则行宽、未闭合引号和超限输入在命令执行前拒绝。
- 单个值填充整个矩形选区；矩阵粘贴要求单个左上角或尺寸一致的选区，不进行隐式重复铺满。最多 20,000 格；任何字段或目标非法均不产生部分写入。
- 一次粘贴/清空形成一条文档历史。Delete 对实际选中的位置清空，支持明确选中的非连续位置，不填充中间未选中的格。
- 已导入的隐藏行列依然属于矩形的逻辑范围；复制/粘贴包含它们。常规方向导航跳过隐藏维度。后续 UI-004 筛选隐藏具有独立的可见复制/写入契约，见 [后续记录](18-m5-structure-and-workspace.md)。

## 性能测量口径

固定生成器覆盖密集 100,000 格（10,000×10）和稀疏 20,000 格（分散在 100,000×256）；后者是桌面范围，不冒充领域 P03 的 1,024 列工作负载。Release，每项 5 次预热加 30 个原始样本，输出 p50/p95、绑定时间、行对象/容器数、托管内存差和进程内存。

计时终点为布局完成后的 Dispatcher.ApplicationIdle，不是显示器呈现帧。`input` 是命令执行加刷新，不含公式重算；另列 `command` 与 `refresh` 分段。纵向滚动测远距离跳转，横向测列定位；100 格选择含回到左上角的布局成本。这些指标不直接等同于 P02 输入事件到下一帧的 Beta 目标。

初轮探索已确认首次仅创建/呈现 17 行；密集表提交和部分滚动样本超出提议预算，需保留原始失败/超预算数据。不能以“测量程序 PASS”宣称所有性能指标达标。

## 系统中文拼音实机验收

首次 computer-use 窗口授权超时后，用户明确要求“重试授权，完成实机验收”。重试成功，使用真实原生按键唤起系统中文拼音候选；中文内容没有通过直接粘贴绕过输入法。截图和工作簿在 `artifacts/validation/m5-grid/20261028-native-ime`，详细版本对应关系见同目录 `acceptance.json`。

| 场景 | 实机结果 |
| --- | --- |
| 直接键入与 F2 | 首个 `n` 保留并出现候选；空格选择“你”，F2 在原值后追加，未丢失原值 |
| 候选期间 Enter | 本机拼音接受原文 `n`，仍停留 B1；第二次 Enter 才提交并移动到 B2 |
| 候选期间 Ctrl+S / 切表入口 / 公式栏 | 不打开保存对话框、不离开组合编辑器；鼠标切换显示先完成/取消组合的状态提示 |
| Escape / 文档历史 | 第一次 Escape 取消候选，第二次取消草稿；A1 原值“你你”保持，随后一次文档撤销回到“你”、重做恢复“你你”，没有多余草稿事务 |
| 公式栏撤销/重做 | 撤销当前中文草稿后再次撤销不召回旧单元格文本；工作簿已提交内容不被文本撤销改变，重做恢复草稿 |
| 公式栏 Tab / Shift+Tab | 中文草稿提交一次，A2 → B2；反向返回 A2 |
| 同格双向交接与自动重算 | 网格候选完成后点击公式栏，旧值提交；重算后输入仍进入公式栏，候选位置正确；公式栏草稿切回网格保留中文 |
| 保存重开 | `accepted.xlsq` 的 A1 为“你你”、B1 为 `n`；UI 重开及包内 worksheet XML 独立核对一致，关闭时无未保存提示 |
| 重开相同表身份 | 先选择 B2，再重开同一文件，选框、就绪编辑器和公式栏统一回到 A1，内容不变 |
