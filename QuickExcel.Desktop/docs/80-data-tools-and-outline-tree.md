# 数据工具与树形分类汇总

2026-11-04，Avalonia 数据页增加快速填充、模拟分析和预测，完善分列、去重与分类汇总入口。本文件更新 [55](55-data-cleaning.md)、[56](56-outline-and-subtotals.md) 中对应的历史实现边界。

## 数据工具

- **分列**：单格自动定位连续数据行，多格来源须为一列。三步向导先显示带工作表行号的原文，再实时预览组合分隔符或固定宽度的切分结果。第三步可点击表头或列内数据，单独设置常规、文本、日期（YMD/MDY/DMY）、跳过或严格数字。返回上一步查看设置会保留列格式；修改切分规则后重新分配列。预览最多显示前 200 行，第三步按全选区识别字段数，完成时处理全部选定行。向导默认“常规”，按高级数字设置识别数值及四位年份在前的日期，无法安全转换的字段保留原文；编号需要保留前导零时选择“文本”。目标起始单元格同表可改，覆盖已有目标内容须确认，整次分列可以一次撤销。
- **快速填充 / Ctrl+E**：先在目标列输入示例，再确认来源与示例区域（不含标题）。支持提取词段、数字段、前后缀、拼接相邻列及大小写转换；仅填充空白，保留已有示例和公式，输出始终为文本。按所有示例验证规则，最低成本规则的预测有歧义时拒绝并要求补充示例。一次最多 20,000 格、16 个来源列、每格 256 字符、总文本 256,000 字符，推断限时 5 秒。此为有界规则推断，不宣称覆盖 Excel 的全部 Flash Fill 模式。
- **数据验证**：数据工具下拉菜单提供设置和清除验证；原有列表选择、输入提示、错误提示、原子校验及文件往返契约不变。
- **删除重复值**：按表头名称勾选判重列，默认勾选“扩展到整条记录的数据列”。连续相邻列随记录一起压缩，避免仅移走键列而破坏对应关系；保留首次出现项。仍在记录区域内压缩并清空尾部，不删除整张工作表的物理行。

数据工具共用不可变预览，覆盖已有目标内容需要勾选确认，确认后通过 DocumentSession 一次提交与撤销。数据、公式缓存或结构变化使预览失效。合并、绘图、富文本、链接/批注和隐藏区域沿用现有保护；不绕过工作表保护、验证或动态数组写入门禁。

## 模拟分析与预测

模拟分析下拉菜单提供：

1. **单变量求解**：指定数值输入、结果公式、目标值和绝对误差。割线迭代发现根区间后使用区间保护；不收敛、错误公式或取消时不提交。确认预览只写回求得的输入值。
2. **模拟运算表**：一变量列表或二变量组合，最多 200 种组合；输出本次计算结果的普通数值表。
3. **方案分析**：输入命名方案及 1–16 个可变单元格的值，最多 200 个方案，生成名称、输入值和结果摘要。摘要可随普通工作簿保存；不实现 Excel scenario XML 对象或持久方案管理器。

所有试算在私有快照中运行，使用 `IsProvisional`、完整重算和独立计算标记，不提交中间值或污染计算器复用缓存。试算仅使用内置公式，不授权或执行工作簿脚本；旧缓存不视为有效结果。桌面计算可取消，整次限时 30 秒。结果表不允许覆盖输入或结果公式，源数据改变后需重新生成。

**预测**接受两列等间距、严格递增的时间/序号和数值，至少 3 个点。支持线性趋势和 Holt 双指数平滑，后者可设置水平/趋势参数。输出历史值和未来预测值表，保留时间轴的日期格式，禁止覆盖历史区域。最多 5,000 个历史行、1,000 个预测期；缺失、重复、不等间距和未重算公式明确拒绝。输出为静态值；未实现 ETS 季节性、置信区间或 Excel 预测工作表的自动图表。

## 分类汇总及树形大纲

对话框使用表头字段名称和汇总列复选列表，支持 11 种 SUBTOTAL 函数、替换现有汇总、追加另一层汇总、每组分页、汇总在上/下方和“全部删除”。按相邻相同分类生成；不隐式排序。插入、替换和删除同时变换区外/跨表公式与已建模条件格式引用，可整体撤销。

替换/删除只识别完整的大纲与 SUBTOTAL 汇总行。汇总行有额外记录、自定义公式、区域不完整或手动分组时拒绝，避免静默删数据。移除汇总也移除配套分组边界分页；其他打印设置继续映射。表、筛选、验证、隐藏普通行列及未建模对象的结构保护保持生效，原有分组与活动筛选混合状态边界不放开。

原网格上方的分组下拉框已移除。行大纲直接在行号左侧呈现树形连接线、明细点、组旁 `+`/`−`，顶部显示 1/2/3（或更多）级别按钮。一级显示总计，二级显示分类汇总，三级显示明细；单组展开保留其他组状态。按钮是带可访问名称和键盘支持的原生控件，网格仅发出操作请求，命令仍由主窗口通过会话执行。折叠后当前单元格定位到可见行。

树与网格共用隐藏/冻结/滚动/缩放坐标；只为可见汇总行创建按钮，未分组时不占侧栏空间。汇总在上方也使用同一模型。列分组仍使用数据页“展开/折叠”操作窗口，本次未增加顶部列树。outline 层级、隐藏、collapsed 与汇总方向沿用 XLSX/XLSQ 原有格式，无新增文件能力。
