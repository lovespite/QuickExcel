“开始 → 样式”保留条件格式，并增加两行可视化样式库。宽窗口直接展示截图中的常规、差、好、适中、计算、检查单元格、解释性文本、警告文本、链接单元格、输出；默认宽度展示六项，展开按钮始终提供全部样式。展开库按常用、标题和总计、主题样式、数字格式分组，共 46 个内置样式。颜色为固定 ARGB；“链接单元格”只是外观，不创建链接。合并样式未实现。

## 本机自定义样式

用户选择将自定义样式保存在本机，供所有工作簿使用。库文件为 Avalonia 用户设置目录下的 `cell-styles.json`，独立于界面设置和工作簿；诊断模式使用隔离的 artifacts 设置目录。最多 128 个样式，JSON 最多 1 MiB；版本、名称、ID、格式和类别均验证。原子替换、独占写入锁和内容指纹防止窗口之间静默覆盖；损坏文件保留并显示错误。

“新建单元格样式…”从当前格格式采样，可以命名并分别勾选数字、对齐、字体、边框、填充、保护。格式按钮在私有单元格文档中编辑数字、对齐/字体、边框、填充、保护，取消不修改库或当前文档。确定保存本机样式；随后点击样式应用到选区。右键支持复制为新样式、修改和删除；管理入口提供键盘可访问的修改和删除。库的修改/删除不追溯改写此前已应用的单元格。

## 格式和事务约定

应用沿用 `CommitEditorsAsync`、可见选区规划、`SetCellStyleCommand` 和 `DocumentSession`：先提交草稿、跳过筛选隐藏行，受已有 20,000 格限制及只读/保护门禁约束，每次选区应用为一个撤销操作。不改变值、公式、链接或批注；字体类设置沿用既有整格字体命令，保留富文本分段并覆盖对应 run 字体。

未勾选类别保持目标格式。已勾选类别复制对应格式，包括明确清除字体色、底色、下划线等；未指定字体/字号采样采用 Microsoft YaHei UI / 11 pt。常规重置全部六类；外观预设保留数字、对齐及保护；数字预设只改变数字格式。样式是直接格式模板，不新增或覆盖工作簿命名样式表。应用结果随 XLSX/XLSQ 持久化，不需要接收方拥有本机库，原有命名样式保留机制不变。
