## 结构和排序契约

- 「结构」菜单作用于选区所在的整行/整列。插入在选区之前，删除包含所选行列，移动目标是移除源块后的最终起始序号，从 1 开始，须在当前显示范围内。M3 引用变换保留相对/绝对/混合及跨表引用的目标语义，拆分连续引用区域会拒绝。
- 改名更新公式和名称中的表引用。删表至少保留一张表，显式确认后将指向被删表的引用变为 `#REF!`，删除其局部名称；一次撤销还原内容、名称与身份。
- 带合并或图片的表继续保守拒绝行列结构变更与排序。UI-008 尚未实现合并/图片锚点变换，不能据本轮称其已通过。
- 排序只移动明确选定矩形内的单元格和已解析样式，不隐式扩展整表、不推断表头，选区应排除表头。按当前列排序，最多 20,000 格，至少两行。
- 随行移动的公式采用复制式位移：相对行引用调整，绝对行保持；混合/跨表引用按各自标记处理，越界引用变为 `#REF!`。矩形外公式及定义名称继续引用原地址。行高/隐藏等行元数据保持原行号，不随排序移动。
- 升序类型顺序：数字、文本、布尔、错误、空白。文本 ordinal-ignore-case 比较；数字按数值；错误按枚举顺序。同键稳定；降序反转非空白比较，空白始终最后。空文本是文本。公式关键列必须有当前修订 Fresh/Error 结果，旧缓存或缺少结果会拒绝；解析失败不留下部分排序。
- 筛选开启时拒绝排序/结构编辑，提示先清除筛选。结构变更及内容/结构撤销重做清除当前表筛选/冻结，避免旧地址被误解；纯样式/尺寸的撤销重做保留视图范围。

## 筛选、剪贴板与冻结

选择含表头的矩形后，按当前列的**显示文本包含**筛选，忽略大小写；第一行保留，区域外行保持可见。空文本匹配全部。模型行号不因筛选重新编号，隐藏数据仍参与计算及保存。

| 操作 | 筛选下的行为 |
| --- | --- |
| 方向导航 | 跳过筛选隐藏行和原有隐藏维度 |
| 复制 | 只复制筛选可见行；矩形缺失的格只能来自筛选隐藏行，其他不连续选择仍拒绝 |
| 粘贴 | 目标包含筛选隐藏行则整批拒绝，不自动压缩映射到可见行 |
| Delete / 样式 | 只作用于选区中筛选可见的格，一次事务 |
| 排序、结构操作 | 先清除筛选，明确完整作用范围 |

文件原有手工隐藏行列沿用 UI-003 逻辑矩形复制/粘贴语义，与本次筛选隐藏不同。筛选不改写文件的 Hidden 元数据。

选择 B2 再冻结，可冻结第一列和第一行。左侧列使用 DataGrid 原生冻结；上方行使用最多 10 行的独立只读参照区，跟随水平滚动、保留真实行号，点击定位主网格原格编辑。参照区最大高度 220 DIP，过高时内部可滚动。它不提供第二套编辑/草稿状态机，不声称与 Excel 多窗格编辑完全等价；参照区和主表可以同时显示同一顶部行。

## 文件工作区与冲突

- Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存、Ctrl+Shift+S 另存、Ctrl+W 关闭工作簿并回到空白工作区。窗口关闭沿用保存/放弃/取消与防重入路径。
- 文件切换先提交网格、公式栏和脚本编辑；非法草稿阻止切换，组合输入保持门禁。取消保留当前文档，失败保存不推进 saved revision，失败打开不替换会话。保存只标记成功写入的 captured Revision。
- 最近文件最多 10 个，大小写不敏感去重，仅成功打开/保存更新顺序。显示完整路径，缺失文件打开失败保留当前工作簿，菜单可清空。配置在 `%LOCALAPPDATA%/QuickExcel/recent-files.json`，不含内容/源码。损坏或无权限不阻止文档读写，配置写失败记日志。验收使用 artifacts 下独立配置，不污染用户列表。
- 打开时用禁止写入/删除共享的只读句柄保护指纹与模型读取；保存使用上次成功打开/保存的 SHA-256，不仅比较时间/长度。保存前、临时包重开验证后且替换前均核对目标内容/存在状态。外部修改、同长度同时间替换、删除或新目标被抢占均失败，保留本地 dirty 和外部文件。提示重新打开或另存其他路径，没有静默覆盖入口。
- `SaveChecked` 属于存储端口，Core 不读取文件系统。既有非版本化 Save 保留给内部夹具和程序调用；桌面使用版本化路径。成功保存的哈希直接来自生成字节，避免把保存后的外部替换当作新基线。
- 这是乐观并发检查，最终核对到 OS replace 之间仍有小竞态窗口，不能当作文件系统 CAS、同步盘事务或完整 FMT-010。多进程竞争、实际同步盘/网络盘与恢复故障矩阵仍在 M6。

### 2026-10-29：重算闪烁与格式触发修正

检查确认四条链路：`WorkAsync` 原先在每轮计算前后禁用/启用整个工具栏和工作区，触发灰显与焦点切换；`RefreshWorkspaceView` 每次清空冻结列并替换 ItemsSource；样式命令复用 `SetCellsCommand` 时丢弃公式缓存并按内容修改失效；样式转换器绑定整个行对象，缺少可随属性通知重新求值的属性路径。

当前规则：

| 操作 | 计算与刷新 |
| --- | --- |
| 字体、填充、边框、对齐、数字格式、清除样式 | `CalculationUnchanged`；保留有效 Fresh/Error 值及诊断，将有效缓存修订迁移到新文档修订；立即更新显示，不安排计算 |
| 纯行高/列宽及其与样式的撤销重做 | 不安排计算；撤销重做沿用当前缓存，不复活历史脚本结果；保留筛选/冻结 |
| 内容编辑、粘贴、清空、替换 | 实际输入变化才设置 pending；编辑/组合输入结束后通过原有调度门禁计算 |
| 排序、移动/插删、改名/删表、隐藏/显示及合并命令 | 仍按既有内容/结构路径失效、安排计算；本轮没有把这些命令改为样式命令 |
| 仅切换选择、筛选或冻结 | 本身不设置 pending；已有内容草稿提交或已有 pending 时仍可能计算 |
| 修改/停用脚本 | 撤销执行许可、使缓存失效；修改源码仍需显式应用，格式操作不授予脚本许可 |
| 显式重算/应用脚本 | 保留显式入口；取消或未提交的重算保留 pending，不能被当成成功 |

格式命令仍先提交原单元格草稿。因此“输入新数值后直接按粗体”会计算，原因是内容提交；纯格式操作以及其撤销/重做不会计算。已有 Stale/Blocked/Dirty/缺失缓存不会因格式操作而变为有效；修订与代次校验继续拒绝在途旧计算/动作结果。
