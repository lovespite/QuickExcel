# XC-0203：录入辅助、公式草稿与键盘导航

2026-10-30 完成声明范围。自动求和、函数补全/参数提示、同表点选引用、F4 和数据边界导航接入现有 EditorController/DocumentSession；没有新增计算函数、文件能力或脚本权限。公式仍由既有解析/计算/保存路径处理。

## 编辑行为

公式栏旁 Σ 和 Alt+= 建议当前单元格的 SUM 草稿：优先取紧邻上方连续数字/公式块，其次取左方，均无则留下空参数。选中建议引用后可修改或点选，Enter/应用才写入，Esc 取消；不批量生成多行/列小计。SUM 包含隐藏记录，状态栏明确说明。只读/富文本单元格不提供直接改写。

网格和公式栏共用有界词法辅助，支持尚未闭合的草稿。补全仅来自 `StandardFunctions.Signatures`，最多八项，↑↓ 选择、Tab 或鼠标接受；已有左括号会复用并把光标置于参数内。参数提示跟踪最内层已注册函数和当前参数序号，区分嵌套括号、逗号及引号字符串。未知函数、名称、脚本和未实现结构化语法不作为补全候选。该列表随后续已实现函数登记扩展，不宣称未登记函数已支持。

F4 对光标所在引用或选中的引用片段依次切换 `A1 → $A$1 → A$1 → $A1 → A1`；范围的端点分别切换，整列引用切换列绝对性。限定工作表拼写保持，字符串、数字科学记数、名称和函数标识不会被改写；包含结构化/外部方括号语法的草稿不处理。多端点/多引用使用逐个端点规则，未以物理 Excel F4 验收所有混合选区行为。

同表点选仅在需要操作数的位置或已有引用处启动；拖动可替换为矩形范围。鼠标手势只改变原编辑框草稿，保留原单元格所有权和模型选区；不调用网格写值，不把点击地址变成提交地址。当前不提供跨表点选和拖动边缘自动滚动，可手工输入已支持的跨表公式。输入法组合期间不补全、切换引用、点选或自动求和。帮助弹层打开时第一次 Esc 收起帮助，随后 Esc 取消草稿；确认提交后仍可整笔撤销/重做。

2026-11-02 起，公式栏或网格编辑器中的有效引用会在网格覆盖层以绿色半透明范围提示；拖动点选时实时更新，光标位于引用文本内时也显示，跨表或无法解析的引用不猜测高亮。该层仅绘制当前可见片段，不改变模型选区、单元格内容或撤销历史。

## 导航

Ctrl+方向键：当前和下一个可见格都有内容时移到连续块末端；否则跨空白找到下一个有内容的格，或到当前产品容量边界。公式即使结果为空字符串也有内容；仅有格式的空白不算内容。隐藏/筛选行和隐藏列跳过；Shift 扩展保持原锚点。

Home 到当前行首，Ctrl+Home 到左上角，Ctrl+End 到已存单元格使用范围右下角；均使用已有可见单元格映射。End 单独进入/退出结束模式，下一方向键使用数据边界规则。Ctrl+Shift+Home/End/方向扩展选区。文本编辑时 Ctrl+方向/Home/End 仍交给 TextBox，不抢夺文本导航。

无数据尾部可将虚拟网格扩至声明的 100,000 行 × 256 列，保留锚点且不分配空白单元格；不是 Excel 的 1,048,576 × 16,384 容量。导航只更新已支持的视图，不制造内容历史。合并格仍由既有网格映射到锚格；未宣称所有 Excel 合并布局的 Ctrl 导航完全等价。
