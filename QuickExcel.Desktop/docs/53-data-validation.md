# XC-0304 数据验证

2026-10-31 完成声明范围，接续条件格式。规则、提示、错误样式和多区域作用范围进入文档模型、历史、XLSX/XLSQ；XLSQ 声明 worksheet-validation requiredFeature。没有发布新包，也未关闭 M4/M6 门禁。

## 支持与编辑规则

支持直接列表、单行/单列范围列表和命名范围，整数、小数、日期、文本长度的八种比较，以及基础标准函数自定义公式。多区域规则的相对引用以第一个区域左上角为基准。提示标题/正文、忽略空白、下拉开关、显示输入/错误提示及停止/警告/信息样式保存。数据页提供设置/修改和清除入口；修改单个现有规则时显示其完整作用范围，清除也先确认完整区域。

选中单元格后显示录入提示；列表选择位于公式栏下方，保留源值类型和文本 ID 的前导零。设置日期条件时接受 yyyy-MM-dd 并转换为 DATE 公式；仅在显式日期规则区域，普通录入/外部文本粘贴的 ISO 日期转换为当前 1900/1904 日期系统的数值。引号强制文本和内部类型化粘贴不猜测转换，无规则区域保留原输入策略。规则不自动改变单元格数字格式。

DocumentSession 在提交前校验整份候选事务，计算所需的标准公式依赖，不读取陈旧缓存或执行脚本。单格录入、公式栏、外部文本/内部类型化粘贴、填充、清除、批量命令和 action 补丁共用该入口。一个失败则整批不提交，错误指出位置及规则提示；停止型不能绕过，警告/信息型须明确确认整批继续，确认后仍按原 revision 检查。撤销/重做恢复原事务。

新增/修改规则保留已有内容，不追溯清空无效值；依赖来源变化也不自动修正已有值。后续直接修改受约束格时再校验。粘贴保留目标验证规则，不复制源格的验证定义。该整批校验是明确的 QuickExcel 策略：Excel 的复制/填充路径可能绕过录入验证，不能把这种一致校验称为完全复刻其粘贴行为。[Microsoft 数据验证说明](https://support.microsoft.com/en-gb/excel/more-on-data-validation?nochrome=true)

## Excel 对照得到的边界

空白与空文本不同。普通范围列表保留类型（文本“10”不等于数值 10）；直接列表按项目文本比较。此次 Excel 版本中，直接列表区分大小写，范围列表的文本比较不区分大小写。勾选忽略空白时，空白的单格条件引用可使比较/自定义规则跳过；命名列表源中有空白也可跳过，直接范围列表没有相同放行行为。布尔值、Unicode 字符长度以及跨日期系统均按独立原生结果实现，具体输入保存在固定夹具，未以 QuickExcel 自己的结果充当期望。

只支持有界、可解释的规则：每表至多 1024 条规则、4096 个区域、4 MiB 估算元数据；不允许重叠区域；直接列表最多 255 字符，范围列表最多 10,000 格；验证计算最多 2,000,000 步、依赖嵌套最多 128 层。时间验证、非默认 IME 模式、扩展验证、脚本/易变或未建模公式保留并报告。无法安全执行的导入验证会阻止内容修改；未修改仍可原字节保存，不能静默移除限制。规则来源损坏或计算失败也不能以警告确认绕过。

名称改名、工作表改名/复制更新规则 AST，复制保留独立名称绑定；规则进入历史和保存预算。含验证的工作簿行列插删/搬移暂明确拒绝，避免尚未验收的相对锚点变化。其他会写入受约束格的批量命令仍受上述校验，可能拒绝原本已无效的内容搬入。

## 验证证据

Excel 16.0 build 20527 x64、语言 2052；使用任务自有隐藏 COM 实例，记录 PID/版本和文件 SHA-256，禁用宏和外链更新，普通打开、重算、保存重开，不使用修复模式。二进制位于 artifacts/compatibility；固定原包 XML 与期望位于两个 excel-data-validation Fixtures。

| xc0304-excel-08 / xc0304-excel-1904-03 | 两种日期系统各 685 个原生案例；数值/日期/长度八种比较、直接/范围/命名列表、空白、自定义、Unicode、相对多区域、错误样式；保存重开稳定 |
| xc0304-probe-07 / xc0304-probe-1904-02 | 合计 45,210 项导入及 XLSX/XLSQ 往返检查，零差异；输出 Open XML schema 零问题 |

原生 Excel 包仍带本项以外的 UI/扩展元数据，探针明确写受支持诊断副本；普通 XLSX/XLSQ 保存另有模型测试，桌面产物按普通保存验收。不把诊断副本称为任意来源的无损普通保存。全解决方案 Release 构建成功，仅现有 NU1900 漏洞源网络警告；未跑全量测试或打发布包。WPF 使用真实处理器和合成事件，不代表物理键盘或 OS IME 验收。

复现入口：scripts/test-excel-data-validation.ps1 的 -Date1904 / -WorkbookPath；CompatibilityProbe 的 data-validation 与 verify-data-validation；桌面 --data-validation-smoke。托管命令均使用 --artifacts-path artifacts/build。早期失败证据保留：Excel COM 值类型调用点、创建时错误条件、反向边界样本、空文本/类型比较、Unicode 和命名列表空白语义均已逐项核对修正。
