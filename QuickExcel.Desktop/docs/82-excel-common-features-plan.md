## E6 日常数据交换与编辑

- **XC-0601 CSV 和 TSV 交换，P1。** 首批增加当前工作表及选区导出，支持 UTF-8、可选 BOM、逗号和制表符。后续接入导入预览、分隔符选择、显式编码选择和逐列文本/数字/日期设置，复用分列的类型转换规则。默认文本导入保留编号前导零和以 `=` 开头的原文。导出明确区分原始值与显示文本，公式采用有效结果并检查缓存状态，格式、多表和对象的取舍在导出界面说明。验收覆盖中文、引号、嵌入换行、空字段、末尾空列、长编号、日期系统、区域数字格式及取消；检查 QuickExcel 与 Excel 双向打开的值、列数和行数。

- **XC-0602 常用公式扩展，P1。** 分批实现 `ROW`、`COLUMN`、`ROWS`、`COLUMNS`，随后实现 `IFS`、`SWITCH`、`SUMPRODUCT`，再推进 `TEXTSPLIT`、`TEXTBEFORE`、`TEXTAFTER`、`SORTBY`、`TAKE`、`DROP`。每批先冻结参数数量、引用与数组返回类型、空白/文本/布尔转换及错误传播，分别确定惰性分支和数组广播范围。复用绑定、依赖索引和 TypedEvaluator，同时接入补全、参数提示及 XLSX 函数编码。验收包含直接参数与范围参数差异、跨表引用、溢出冲突、增量重算、撤销和保存重开，使用独立 Excel 结果对照。各函数单独登记支持范围。

- **XC-0603 定位条件，P1。** 增加空白、常量、公式、错误值和可见单元格选择，限定为当前选区或当前表已用范围。选择结果复用多区域选择模型，对范围数和扫描量设定可取消预算。先提供选择、统计、格式和清除流程，多区域复制写入随 XC-0604 接入。验收覆盖空白与空字符串、公式返回空文本、手动隐藏与筛除行、合并格、保护单元格以及远端稀疏数据，选择操作保持会话导航语义。

- **XC-0604 可见行复制粘贴，P1。** 建立明确的源行与目标行映射，增加“复制可见单元格”和“粘贴到可见单元格”入口。首批支持值与基本格式，显示目标记录数、隐藏行处理和覆盖范围；源与目标数量不匹配时要求调整。第二批补齐公式的逐格相对引用转换，并与 78 号外部剪贴板协议联调。实现前完成富文本、链接、批注、验证、条件格式和数组所有权的映射规则，无法映射的组合继续走既有拒绝路径。验收覆盖隐藏行、筛选变化、跨表/跨实例、保护和验证失败、粘贴前数据变化，整次操作只产生一条历史且失败时整批回滚。现有入口见 [编辑与剪贴板](../../QuickExcel.Desktop.Avalonia/Views/MainWindow.Editing.cs)及 [互操作契约](78-excel-clipboard-interoperability-plan.md)。

- **XC-0605 筛选与排序扩展，P1。** 分批实现填充/字体颜色筛选、前 N 项与前 N 百分比、按年月日分组的日期筛选，随后评估图标筛选、从左到右排序及地区排序规则。颜色筛选明确采用单元格基础样式还是条件格式后的显示样式；前 N 项覆盖并列值，日期分组覆盖两种日期系统。模型、桌面、XLSX/XLSQ 保存及重新应用同步交付。验收包含多列条件叠加、空白/错误、手动隐藏、Table 过滤、编辑后重应用和 Excel 往返。既有契约见 [筛选与排序](50-filter-and-sort-persistence.md)。

- **XC-0606 运算粘贴和条件格式补缺，P2。** 运算粘贴先支持数值加减乘除及跳过空白，明确公式目标、文本、错误和除零行为；条件格式先补“发生日期”入口和对应规则读写。分别作为独立任务验收，覆盖批量失败回滚、撤销和真实 Excel 对照。两项均复用现有命令、验证和格式模型。

- **XC-0607 公式审核，P2。** 先提供直接引用/从属列表及点击定位，再增加网格箭头、错误定位和逐步公式求值。依赖视图复用 WorkbookDependencyIndex，展示实际计算状态和不完整依赖。逐步求值先覆盖受支持内置公式，脚本公式展示当前计算结果和状态。验收覆盖跨表、名称、数组、循环、缺失目标、旧缓存及结构编辑后的列表刷新。

E6 每个完成项都应通过用户正常菜单、快捷键或文件对话框进入。新增复杂选择与写入路径必须同时验证取消、过期预览、一次撤销和失败回滚。

## E7 恢复与内容编辑

- **XC-0701 自动恢复草稿，P1。** 接续 FMT-010，保存带原文件路径、内容指纹、会话身份、修订和完成时间的独立恢复副本。首轮沿用已有方案中的 30 秒触发与 60 秒恢复窗口作为待测目标，实际写入采用合并排队和原子替换。草稿写入串行化并验证修订，关闭、另存及文档切换时重新核对身份。明确正文、公式栏和脚本编辑器中未提交草稿的恢复范围。启动后展示可恢复项、来源文件和时间，恢复到新文档并要求另存。恢复文件沿用脚本停用契约。正常保存、主动放弃和清理策略分别定义，多实例使用独立身份与租约。验收注入写入中止、磁盘满、损坏末次副本、源文件外部变更和进程崩溃，能够找回最后一份完整副本并报告未记录时间段。现有任务见 [M6 恢复与发布](05-implementation-plan.md)。

- **XC-0702 单元格富文本编辑，P2。** 在现有 run 模型上增加局部选字、字体/颜色/粗斜体修改和文字替换，覆盖插入位置的格式继承及 run 合并。网格、编辑器、自动尺寸、打印/PDF 和存储使用一致的文本表示。输入法组合期间保留原单元格草稿归属，一次编辑形成一次撤销。验收包含中文组合输入、换行、混合字体、链接/批注附件、复制粘贴、保存重开和整格格式命令，保留显式转为普通文本的入口。依托 [富文本契约](36-xlsx-rich-text-links-and-notes.md)。

- **XC-0703 超链接与线程评论桌面编辑，P2。** 超链接先补新建、修改、删除和目标查看，覆盖内部地址、网页及 mailto 的读写，地址执行继续遵守 AGENTS.md 的惰性链接契约。线程评论复用已实现的 Comment/CommentReply 事务、UUID、作者、回复和解决状态，增加桌面查看、回复和解决入口。带旧版显示副本的导入讨论依照现有只读保留范围处理。验收覆盖真实附件关系、导入评论、回复删除、保存重开、撤销和对象身份，结构与剪贴板映射随对应命令单独验证。依托 [Script API P2](79-script-api-redesign.md)。

E7 的恢复验收同时检查正常退出、异常退出和多实例行为，性能记录包含恢复写入时的输入响应。富文本与评论能力按可编辑对象类型分别公布。

## E8 月报与图表分析

- **XC-0801 多字段透视表，P2。** 将行字段、列字段和度量扩展为有序集合，提供字段列表和增删/重排入口，覆盖“地区 → 门店”及销售额、销量双度量。设计字段身份、布局和旧单字段文件的兼容读取，继续复用创建/刷新命令、缓存和过期提示。首批交付一种明确的表格布局，逐项验证明细、分组小计和总计，平均值总计从源记录计算。验收包括源列改名/插入/删除、混合类型、空白、刷新扩展覆盖、撤销和 Excel 保存重开。

- **XC-0802 透视筛选与日期分组，P2。** 依赖 XC-0801 增加报表筛选字段、按年/季度/月分组、排序和展开折叠。切片器、时间线和多透视表联动另设后续子项，在缓存共享与过滤状态建模后进入。验收明确筛选对明细、小计和总计的影响，覆盖共享缓存、源变化和显式刷新。已有范围见 [透视实施记录](74-e5-implementation-log.md)。

- **XC-0803 常见图表类型与坐标轴，P2。** 首批实现水平条形、堆积与百分比堆积，随后实现柱线组合和次坐标轴，再评估圆环、面积和迷你图。图表模型先支持各系列类型及轴身份，存储、屏幕与打印共用该表示。验收覆盖负数/空值/错误值、筛选数据、不同数量级、源范围变更、移动缩放、图表复制、XLSX/XLSQ 往返和 Excel 重开。继续以当前源数据生成图表缓存。依托 [图表对象契约](73-charts-and-drawing-objects.md)和 [图表筛选](75-chart-source-highlights-and-filters.md)。

- **XC-0804 趋势线与图表细节，P2。** 在明确的散点和折线模型上增加线性趋势线、公式与 R² 显示，随后逐项扩展误差线和日期轴。计算、源值排除规则和格式独立验证，视觉验收覆盖屏幕、PDF 与 Excel。每种趋势线和轴类型分别记录样本及数值容差。

- **XC-0805 财务函数与模拟分析，P2/P3。** 财务公式先补 PMT、PV、FV、NPV、IRR，冻结现金流时点、利率周期、迭代初值、不收敛和多根边界后实现。模拟分析先增加可保存的命名方案，再评估原生模拟运算表和季节性预测。持久方案涉及新的文档模型与文件契约；季节性、缺失时间点、置信区间逐项验收。当前静态结果表、线性及 Holt 预测继续按已有范围使用。[数据工具现状](80-data-tools-and-outline-tree.md)

E8 每项应包含一份可供用户复现的业务样例，并验证在 QuickExcel 编辑后交回 Excel 的布局、数据与刷新行为。复杂图表另做共享渲染和 PDF 定向检查。

## 验收和交付要求

每项按以下步骤交付，状态依次为待开始、实现中、待验收和完成。

2. 通过既有 Core 命令、EditorController 和 DocumentSession 实现写入。异步预览和结果核对会话、工作表、修订及计算状态。新增附件和引用变换先完成映射，再扩展操作入口。
3. 运行受影响的定向测试和对应 Avalonia UI 检查。覆盖新旧文件、撤销/重做、失败回滚和保存重开；既有测试能够验证的行为直接复用。性能测试单独执行并留存原始数据。
4. 产品代码按 AGENTS.md 更新版本，修复提升 patch，小功能或优化提升 minor，重要功能或大改动提升 major，升级时重置较低版本位。引入第三方组件时同步设置页、随包版权信息、许可证和修改声明。
5. 按用户本轮要求，在 E6/E7 全部定向检查通过并独立提交后统一执行本地发布与生产自检，核对 `active-windows.json`、新包清单和 `Start-QuickExcel.cmd` 的解析路径。发布或自检失败时保留上一个活动包，将该项维持在待验收状态。
6. 更新本计划中的任务状态、对应专题和总进度入口，记录源码身份、实际支持范围、证据目录、活动包与剩余限制。
