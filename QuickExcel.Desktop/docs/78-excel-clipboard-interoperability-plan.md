# Excel 与 QuickExcel 剪贴板互操作方案

2026-11-04。状态：**基础交换链路已实现，P1 值/日期/格式/合并及 P2 相对引用公式已取得定向证据，扩展验收继续进行**。当前范围为 Windows 桌面版 Excel 与 QuickExcel Avalonia 的双向复制粘贴；具体实现、证据和未完成项见第 8 节。

### P0 实测调整（2026-11-04）

Excel 16.0 build 20527、界面语言 2052 的真实系统剪贴板提供 UTF-8 `XML Spreadsheet`（尾部 NUL）、`HTML Format` 和 `Biff8`。普通 XML 粘贴会重设 Excel 目标工作簿的日期系统，因此生产对外发布改用带 `x:str`/`x:num`/`x:bool`/`x:err` 的 HTML；XML 仅以应用私有格式发布，供其他 QuickExcel 实例读取。Excel → QuickExcel 仍优先读取 Excel 原生 XML。已实测 HTML 普通粘贴保持目标 1900/1904 日期系统、原始类型及常用格式。

XML DateTime 提供日历日期，但对时间/累计时长缺少源日期系统，会产生 1462 天歧义。实测 Excel 剪贴板 Biff8 **省略 DATE1904**，因此采用严格有界的辅助数值读取器：只打开 CFB 的 Workbook 流，读取矩形尺寸、NUMBER/RK/MULRK 和 FORMULA 的数值缓存，与同一系统数据对象的 XML 日历日期配对确认纪元并保留原始 double。它不解释公式 token、字符串、对象或宏，不实现 BIFF 完整导入或二进制写出。缺少原始数值时拒绝歧义时间值，不猜测；源时间和累计时长保持原值，日历日期转换到目标日期系统，不修改目标工作簿日期系统。

Excel XML 的绝对/混合引用已经重定位到选区坐标，未提供原选区位置；首批公式互通限定普通函数、非限定相对引用，绝对/混合引用、名称、跨表/跨工作簿、数组及 UDF 明确拒绝。HTML `x:fmla` 接受选区坐标的 A1 表示；对外公式若引用复制区域上方/左侧，要求扩大复制范围或明确复制结果值。未引入完整 BIFF 公式实现，不宣称原方案中的全部公式范围已通过。

P1 是首个可独立交付的阶段，目标是满足日常表格搬运。现有工作簿内部剪贴板继续遵循 [40 号契约](40-internal-clipboard.md)，本方案不将内部复制的验证结果视为跨应用互通已经完成。Linux、macOS、Excel 网页版及其他表格软件需要独立验收，不包含在首版兼容声明中。

当前已经存在基础文本互粘路径，但它不能可靠交换 Excel 原始数据语义。例如数值 `0.12` 显示为 `12%` 时，显示文本无法单独表达底层值和数字格式；文本 `"123"` 与数字 `123` 也可能在重新解析时失去区别。外部粘贴需要直接构造经过验证的类型值，不能把全部数据绕回用户输入字符串解析。

内部 `WorkbookClipboard` 绑定文档和修订，样式 ID 也属于来源工作簿。外部剪贴板不得直接反序列化为此对象，不能通过移除身份校验来复用内部粘贴。

## 3 多格式交换路线

一次复制同时发布多种表示，粘贴按操作所需能力选择。Windows 支持同一内容的多格式剪贴板，Avalonia 提供平台格式和字节载荷接口，见 [Windows 剪贴板格式](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats)及 [Avalonia 剪贴板接口](https://docs.avaloniaui.net/docs/services/clipboard)。

### 3.1 XML Spreadsheet

将 `XML Spreadsheet` 作为优先验证的类型化通道，用于原始值、类型、格式，并评估公式及源位置信息。Microsoft 的 [XlRangeValueDataType 文档](https://learn.microsoft.com/en-us/office/vba/api/excel.xlrangevaluedatatype)说明 XML Spreadsheet 表示可以包含值、格式、公式和名称；这是对象模型表示能力，不等于当前 Excel 剪贴板必然提供或接受全部字段。

P0 必须确认实际格式名称、编码、边界、普通粘贴的接受行为，以及源位置、日期系统和公式信息是否足够。不能仅用 `Range.Value` 的 XML 导出结果代替真实剪贴板样本。如果该通道不足以满足某项保真要求，应在 P0 调整该项范围或评估补充格式，不把未经验证的能力带入 P1。

首选路线不要求实现 BIFF8/BIFF12 或 OLE 嵌入对象解析；需要引入时单独评估工作量和范围。剪贴板 Excel 数据不能直接假设为一份 XLSX。

### 3.2 HTML 表格

使用 HTML 作为常用格式兼容通道，支持表格结构、静态样式、跨行跨列和经过验证的 Excel 扩展信息。样式可能位于片段外的上下文中，读取时需要结合实际表格和样式定义，不能只截取可见文本。

Windows 注册名为 `HTML Format`。CF_HTML 使用 UTF-8，`StartHTML`、`EndHTML`、`StartFragment`、`EndFragment` 是字节偏移；中文、多字节字符、片段边界和异常偏移需独立测试，见 [CF_HTML 规范](https://learn.microsoft.com/en-us/windows/win32/dataxchg/html-clipboard-format)。平台编码和封装由适配层处理，不假定其他系统使用相同格式名。

HTML 的显示文本不能独立保证原始数值精度、数据类型或公式。只有经过验证的类型信息才能用于类型化导入；只有显示表示时，应按其实际能力降级。HTML/XML 仅作为数据解析，不执行脚本，不加载远程样式、图片、外部实体或其他资源。

### 3.3 Unicode TSV 与内部令牌

TSV 保留现有矩形、引号和换行处理，作为纯文本兼容路径。只有文本时保留现有显式公式策略，不能声称恢复了原始类型或格式。类型化通道中标记为文本的 `=...`、数字字符串和布尔字符串必须保持文本。

同一会话内有效的内部令牌继续优先使用已有内存捕获。过期或取消的内部剪切不得悄悄转成另一种粘贴语义。其他应用替换剪贴板后，不把旧捕获与新文本或新格式组合使用。

外部格式候选顺序为经过验证的 XML Spreadsheet、HTML、TSV，最终由 P0 冻结。选择还需考虑用户操作：只贴格式不能回退为文本粘贴；格式缺失、格式损坏和不支持某项语义应产生不同诊断。读取到损坏的丰富格式时，不得通过静默选择较弱格式伪装为完整成功。

## 5 交互与数据契约

### 5.1 粘贴模式

- 普通外部 Ctrl+V：P1 贴结果值和支持的格式及合并布局。QuickExcel 普通复制向外发布相同语义，内部复制仍使用原有完整捕获。
- 只贴值：保留来源类型化结果及目标格式，不经过显示字符串重新解析；富文本取文本须由该显式模式授权。
- 只贴格式：保持目标内容，沿用内部合并布局和覆盖格内容规则；来源没有可用格式时明确拒绝。
- 粘贴公式：P2 接入已有显式入口，区分真正公式字段和以等号开头的文本。
- 复制含公式：P2 为 QuickExcel 向 Excel 输出公式提供明确操作；普通结果值复制不隐式变为公式导出。

单格源填充目标矩形、多格源选择左上角或同尺寸目标等行为沿用既有规则，不自动增加多格平铺。外部转置不作为 P1 完成条件。编辑控件和输入法组合态的快捷键归属继续遵守现有门禁。

### 5.2 公式与结果

P2 当前支持普通标量函数和非限定相对引用。绝对/混合引用因 Excel XML 缺少可靠源位置而明确拒绝，列为后续范围。相对引用使用公式语法模型完成变换，不通过字符串替换调整引用。

跨工作簿链接、跨表依赖、名称、结构化引用、动态数组和脚本 UDF 分项评估。缺少依赖上下文时不得仅因目标存在同名工作表、名称或函数就静默绑定。不能支持的公式由用户显式选择结果值，或者整批拒绝。未知公式的保留策略继续遵守 [35 号契约](35-xlsx-preserved-formulas.md)。

外部公式缓存表示来源提供的结果，不是 QuickExcel 新计算出的 Fresh 结果。缺少结果时不能贴成空白；已知过期的结果须按既有显式缓存策略提示。脚本 UDF 首先只交换结果值，不通过剪贴板复制、授权或执行脚本模块。

### 5.3 日期及精度

类型化通道直接传递数值和文本类型，避免用显示字符串恢复数值精度。长编号若来源是文本，必须保持文本；来源已作为数字丢失的精度不能由剪贴板恢复。

日期是底层值、数字格式及日期系统的组合。P0 必须确认交换格式是否提供日期系统或明确日期值，并固定不同日期系统之间的转换规则。来源信息不足时不猜测日期语义；跨系统日期互通不能因此被标为已通过。

### 5.4 现有保护与降级

只读状态、单元格保护、数据验证、完整合并范围、隐藏行列、筛选目标以及富文本/附件保护继续有效。目标含筛选行时不能静默跳行；来源可见行导出沿用明确的文本语义，丰富格式的可见行压缩需独立设计。

完整粘贴识别到不能保留的附件、富文本或规则时说明具体限制，允许用户改选已支持的显式模式。不能以本次扩展为由取消 [36 号富文本、链接与批注保护](36-xlsx-rich-text-links-and-notes.md)。仅贴值也不得绕过目标富文本替换的既有显式转换要求。

2026-11-04 用户授权的筛选列头例外：来源只有筛选标记时，普通粘贴导入值、受支持的静态格式和合并布局，提示未复制筛选按钮/条件；若同时存在其他已识别的来源限制，普通粘贴自动只贴类型化结果值并说明原因。该例外不扩展到显式只贴格式/公式，也不改变目标富文本、保护、隐藏/筛选行、验证及损坏载荷的拒绝规则。实现和证据见第 9 节。

跨应用粘贴不提供可靠的来源删除确认，因此不会自动清空 QuickExcel 或 Excel 的剪切来源。内部剪切仍仅在已有完整移动事务成功后消费；界面应说明跨应用行为，不能把复制结果显示为移动完成。

### 5.5 大小与异步状态

P1 沿用单次粘贴 20,000 格和现有文本 4 Mi 字符限制，目标地址服从当前 `WorkbookLimits`。丰富格式增加独立的字节、节点、深度、样式数和合并展开上限，具体预算在 P0 测量后冻结，不沿用脚本 IPC 限额作为剪贴板依据。

从同一系统剪贴板对象读取候选格式并尽快释放，避免分别读取时混合两次复制的内容。异步读取、解析或提示期间保留会话、工作表、修订和目标范围身份，提交前重新验证。占用、超限、取消、过期或损坏载荷均不产生部分写入。

P1 可独立交付。P2 的准确范围以 P0 样本和依赖信息为依据；若需补充二进制格式，先更新方案及工作量。富文本、附件、规则、对象、多选、跨应用移动和其他平台属于后续切片，不因基础编解码器可扩展就视为已实现。

| 文本与形状 | 中文、多字节字符、引号、制表符、单元格内 CR/LF、尾部空白、全空矩形；检查完整尺寸和内容 |

## 9 筛选列头粘贴（2026-11-04）

真实 Excel 16.0 build 20527 样本表明，普通筛选区域的 XML 会包含 `Names/NamedRange` 和单元格 `NamedCell`，名称为 `_FilterDatabase`，却未必包含 `AutoFilter` 元素。旧检查将其与普通用户名称一起拒绝，导致包含筛选列头的正常数据也无法普通粘贴。探测载荷保存在 `artifacts/clipboard/filter-probe-20261104-084022/`。

现将已知 SpreadsheetML 筛选名称（`_FilterDatabase`、`_xlnm._FilterDatabase`）和 Excel 命名空间的 `AutoFilter` 单独标记。它们不再阻止单元格粘贴，也不在目标建立名称、筛选按钮、条件或隐藏状态；状态栏明确说明。其他用户名称、批注、规则和样式限制仍保留诊断。

`ExternalClipboardPastePolicy` 只对带已识别筛选标记的普通粘贴实施自动降级：仍有来源限制时改为 `CellPasteMode.Values`，保留目标格式，来源公式成为结果值，文本编号等保持原始类型。它不捕获并吞掉解析/提交异常，不转读显示文本，不允许缺失公式结果变成空白；显式格式/公式操作不会变成值写入。单次提交、一次撤销和目标保护仍由原外部命令负责。

## 10 样式及图片／图表互通（2026-11-04）

SpreadsheetML 与 CF_HTML 现在双向保留下划线（单线、双线、单会计、双会计）、删除线、细／中／粗实线及发丝线、已建模的虚线／点线／双边框、缩进和正负文字旋转。Excel `VerticalText` 与 HTML `layout-flow` 的竖排编码可以保留，但竖排显示仍受原有渲染限制。HTML 中整格 `<s>`／`<strike>`／`<u>` 可以导入；局部文字装饰仍有诊断，不视为完整富文本支持。未建模的中虚线／点划线等不会伪装为细线。HTML 仍遵循显示文本策略，样式验证使用显式“只贴格式”，不推断原始类型。

可编辑图表有两条通道：

- **Excel → QuickExcel**：解析有界 Office `Art::GVML ClipFormat`，将源缓存导入独立的“图表数据”工作表。支持闭合模型认可的单个柱形图、折线／平滑折线图、饼图和散点图；所有源引用改写为新数据表引用，不打开源工作簿或外部链接。图片与可编辑选择互相独立；可编辑失败不静默转图片。
- **QuickExcel → Excel**：同时发布 Office 图表和 PNG。图表系列使用 `strLit`／`numLit` 值数组，因此 Excel 中可以修改图表和系列值，且不引用不存在的源工作表、不误连到目标同名区域。GVML 的 `graphicFrame` 子节点顺序与 XLSX 的顺序不同，已由真实 Excel 粘贴验证。
- **QuickExcel → QuickExcel（含跨实例）**：额外使用私有、有界 XLSX 数据快照，保留全部已建模图表类型、系列／点筛选和旋转。完整数据与图表作为一个命令提交、一次撤销／重做；数据表可继续编辑。源公式必须已有新鲜结果，复制不会携带脚本或源公式；主题颜色和字体转为模型的具体值。

图表包最多 16 MiB，累计展开 16 MiB、解析预算 32 MiB、128 条目；图表 XML 最多 512 KiB，系列和点数沿用 16／4096 限制，引用值最多 20,000 格。未知绘图属性、附加关系、组合图表、复杂布局和坏缓存明确拒绝。外部图表筛选可能缺少隐藏点缓存，因此要求选择图片或取消图表筛选后再复制；QuickExcel 私有通道使用完整数据，不受此限制。瀑布图、漏斗图及筛选图表目前对外发布图片，在 QuickExcel 中保留可编辑形式。含对象的整片单元格区域、任意富文本及仅 EMF／SVG 的复制仍未开放，不放宽原有附件保护。
