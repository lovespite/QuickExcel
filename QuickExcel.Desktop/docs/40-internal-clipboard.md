# XC-0201：工作簿内复制、剪切与选择性粘贴

2026-10-30 完成声明范围。开始功能区与 Ctrl+C/X/V 接入内部剪贴板，保留类型、公式、有效单元格样式和完整富文本。外部 TSV 显式公式策略保持；不启用 Excel HTML、外部富剪贴板或跨文档对象复制。

2026-11-04 补充：Windows 外部类型化剪贴板现已单独接入，范围和证据见 [78 号互操作方案](78-excel-clipboard-interoperability-plan.md)。本页的令牌、身份和修订约束继续适用；内部复制保留合并覆盖格内容，外部导出遇此内容明确拒绝，可由用户选择复制结果值来展开布局。

## 命令与交互

Core `WorkbookClipboard` 是最多 20,000 格的不可变内存捕获。系统剪贴板仅承载随机令牌及既有显示文本 TSV，不承载领域对象。桌面要求令牌、DocumentSession 身份和修订匹配；本次成功复制粘贴可延续捕获并更新修订，其他编辑、撤销/重做、重开或 Esc 使旧捕获失效。重复及重叠复制使用原捕获，不读取已被前一次粘贴覆盖的源内容。

`PasteCellsCommand` 通过 EditorController/DocumentSession 一次提交；验证失败不写入、不增加历史，整批一次撤销。只贴格式沿用计算结果。选择左上角或与输出相同大小的矩形；单格源可填满目标，不自动平铺多格源。桌面仍限制 100,000 行 × 256 列。

| 操作 | 语义 |
| --- | --- |
| 完整复制 | 保留值类型、公式、源有效样式及合并范围，空白也覆盖目标；富文本保留所有 runs |
| 只贴值 | 捕获的字面值或公式结果成为同类型字面值，保留目标格式；不经显示字符串重新解析文本 ID、数字或错误 |
| 粘贴公式和常量 | 公式调整引用，常量保持类型，保留目标格式；源富文本常量取纯文本 |
| 只贴格式 | 使用源有效单元格样式及合并状态，保持目标内容；不复制行高、列宽或附件 |
| 转置全部 | 交换源矩形和合并范围的行列并保留类型、样式；公式使用单独的转置引用规则 |
| 剪切 | 先标记，成功完整粘贴才移动并消耗标记；不支持选择性/转置剪切；重叠区域先捕获再清理/放置 |

公式缺少缓存时拒绝只贴值，不能冒充空白。明确选择只贴值可使用已有旧缓存，状态栏说明来源缓存未重算；复制不把缓存标成 Fresh。未知导入函数拒绝引用变换，可选择只贴值。只读公式工作簿仍由会话拒绝写入，粘贴不启用脚本。

Ctrl+Shift+V 和公式菜单：内部捕获按公式/常量模式，外部文本按既有显式输入解析策略。普通外部 Ctrl+V 保持 `=...` 为文本。系统剪贴板被其他程序替换后使用外部文本路径，不把旧领域对象配上新文本。

## 引用与限制

普通复制通过共享 AST 平移相对行列，保留绝对/混合标志、显式工作表及字符串内容；整列引用只平移列。单格引用越界生成 `#REF!`；范围端点越界的 Excel 语法暂不能完整表达，整批拒绝，不静默删除仍有效的端点。

本机 Excel 16.0 build 20527 的转置规则已独立验证：单格全相对引用旋转偏移，带 `$` 的单格引用保持；范围至少一个端点全相对时整体旋转并交换行/列绝对标志，两端均带绝对分量时保持。16 种端点标志组合有固定对照。整列引用转置需要尚未建模的整行语义，明确拒绝。

剪切复用结构命令，指向完整移动范围的引用（包括绝对引用）随对象移动，跨表移动的公式仍可引用来源表中留下的单元格。只覆盖公式引用范围的一部分、来源或目标表设置了打印区域/重复标题、区域与图片或图表相交、导入公式含未确认函数时，结构保护继续生效。跨表复制涉及局部名称时仍拒绝。

隐藏行列中的内部复制/粘贴拒绝；源含隐藏/筛选行时普通复制仍可导出可见行的显示 TSV，并标为“仅显示文本”，不创建内部捕获，剪切则拒绝。超过 20,000 格的普通复制也只使用既有有界显示 TSV。目标含筛选行不得静默跳行；源捕获后改变筛选也重新检查。冻结仅影响视图，不改变模型地址。

2026-11-04：内部复制支持包含完整合并单元格的矩形，完整粘贴和只贴格式均以来源合并布局覆盖目标范围的合并布局。合并来源可合并普通目标，普通来源可取消目标合并；单个普通来源的格式可填满并取消选中合并区域。跨表复制、转置和一次撤销/重做同时保留合并布局；部分覆盖源/目标合并区域仍整批拒绝。只贴值/公式保留目标合并状态，单个普通来源的内容粘贴到一个选中合并格时写其左上角。

2026-11-05：在同一工作簿中，选中包含完整合并区域和完整 Excel 表格（含表头、数据与汇总行）的矩形，按 Ctrl+X，再在目标左上角按 Ctrl+V。支持同表重叠和跨表移动，一次撤销同时恢复两端。合并覆盖格中的输入、样式和公式随区域移动，目标范围内完整的旧合并由来源布局替换。空白单元格携带来源的有效样式，腾空的位置重新使用当地行列样式。行高与列宽属于工作表。

表格保留编号、名称、列定义、表样式、计算列和汇总公式。筛选和排序的范围及列号随表格平移。其他工作表中的结构化引用、A1 引用和定义名称会按来源坐标更新。部分选中表格、目标碰到另一张表格、仅覆盖一个剩余合并区域的一部分，都会整批拒绝。来源或目标工作表含数据验证、条件格式或已启用的工作表保护时，剪切仍受限；透视表、批注/链接和文件兼容性也沿用原有保护。

只贴格式严格保留目标内容，包括新合并区域覆盖的非主格值和公式，取消合并后重新显示；这与本机 Excel 16.0 的 PasteSpecial formats 对照一致。完整复制也保留来源已存在的覆盖格内容。合并布局变化会使公式结果重新计算（包括数组溢出阻挡），单纯样式变化仍沿用已有缓存。保存 XLSX/XLSQ 均保留覆盖格输入。普通「合并」命令仍保留内容冲突提示，不隐式删除或隐藏已有输入。

图片/图表与复制或粘贴矩形相交时仍拒绝。完整复制涉及源/目标超链接或批注时拒绝，显式只贴值/公式/格式保留目标附件；新增合并不能遮盖非主格的链接/批注。剪切沿用整簿附件结构保护，不放宽 XC-0107 的 VML/链接约束。只贴格式遇任一侧富文本时拒绝，避免错误映射字符格式；普通内容覆盖目标富文本仍要求先显式转换。富文本完整复制已通过逐字符 Excel 对照。
