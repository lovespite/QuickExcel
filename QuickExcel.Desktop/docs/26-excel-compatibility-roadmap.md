# XLSX 兼容性与 Excel 功能对齐计划

更新：2026-10-30。**当前重点工程，按用户明确要求优先推进。** 本计划扩展 M2/M3 已交付的支持子集，并继续 M5 的日常工作流；不重开历史里程碑，也不将 M6 安全、恢复和发布门禁视为已完成。总进度见 [实施计划](05-implementation-plan.md)。E0 首切片已开始实施，矩阵、比较工具和证据见 [27 号记录](27-xlsx-compatibility-baseline.md)；以下未勾选项仍未整体完成。

目标是让常见的名单、台账、报价、统计和报表 XLSX 能可靠打开、显示、编辑、计算，再交回 Excel 使用。先解决高频文件中的数据/格式损失和基本操作缺口，再增加分析与复杂对象能力；不以按钮数量或“文件能打开”衡量兼容性。

## 1. 排序规则与范围

下列重要性和常用程度是针对上述业务场景的产品判断，**不是用户遥测或 Excel 全体用户使用率统计**。E0 样本盘点后可根据真实文件调整，须记录理由，不删除失败案例。

| 维度 | 取值与用途 |
| --- | --- |
| 优先级 | P0：避免错误结果/静默丢失及支持后续工作的基础；P1：日常工作必需；P2：常见进阶场景；P3：复杂扩展 |
| 重要性 I | 5：阻止完成主要工作或破坏数据；4：显著影响效率/交付；3：特定场景有价值 |
| 常用程度 F | 5：几乎每次编辑/查看；4：常见业务文件；3：部分分析/报表；2：较专门场景 |
| 复杂度 | S：局部规则/入口；M：单个能力贯穿模型、存储或 UI；L：跨多层且影响引用/保存；XL：新增计算、布局或分析体系。是初步相对评估，不是工期承诺 |
| 排序原则 | P0 先行；同优先级先做重要、常见且成本较低的项。高成本高价值能力拆为读取/保留、显示、编辑三个可验收切片，不等待“全功能”一次交付 |

基准以 Windows 桌面 Excel 常见 XLSX 为主；样本必须记录实际 Excel 版本/build、语言、日期系统。Microsoft 365 专属函数与传统函数分开标注，不能以某版本 Excel 本身不支持的结果评价实现错误。文件结构参考 [Microsoft SpreadsheetML 结构说明](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/structure-of-a-spreadsheetml-document)，函数分类与版本适用范围参考 [Excel 函数分类](https://support.microsoft.com/en-us/excel/excel-functions-by-category)；二者不提供本计划的使用频率排名。

每项分别标记 **读取 R / 显示 D / 计算 C / 编辑 E / 写回 W**，无关维度标为不适用。“原包不变保留”不能标为可编辑写回，“保留公式缓存”不能标为已支持重算。只有勾选项所述范围全部验收后才能完成该项。

## 2. 已有基础清单（限定当前子集）

- [x] **BASE-01 类型与存储**：XLSQ v2、XLSX 数值/文本/布尔/标准错误、空白/空文本、日期系统、普通/共享公式及缓存、稀疏内容；容量与拒绝边界见 [M2 记录](09-m2-files-and-types.md)。
- [x] **BASE-02 安全往返基础**：工作簿不变时保留原 XLSX 字节；编辑后的未知损失阻止普通保存，显式另存受支持副本；原子保存、写后校验及外部文件指纹检查已接入。
- [x] **BASE-03 基础呈现**：字体、实色填充、基础边框/对齐、换行、合并、基础浮动图片、行列尺寸/隐藏；主题/索引/tint 颜色、行高单位、宽列、首次布局与切表修复见 [25](25-xlsx-rendering.md)。主题字体、完整继承样式、富文本仍有缺口。
- [x] **BASE-04 数字和日期显示子集**：常见整数/两位小数、千分位、百分比，以及已列出的日期/时间/累计时长格式。实现入口为 `CellDisplayFormatter`；不将已有百分比格式重新列为全新功能。
- [x] **BASE-05 计算子集**：跨表 A1 引用、定义名称、依赖/循环、标准公式增量求值；SUM/AVERAGE/MIN/MAX/COUNT/COUNTA/PRODUCT、IF/IFERROR、AND/OR/NOT、ROUND/ABS、基础文本、INDEX/MATCH/VLOOKUP、TODAY/NOW 等。精确边界见 [M3 矩阵](10-m3-calculation.md)，未列函数不能据此声称支持。
- [x] **BASE-06 日常界面子集**：编辑/撤销、范围选择、TSV 值粘贴与显式公式粘贴、查找替换、行列结构、类型化筛选/多键排序、会话冻结、Ribbon、尺寸拖动及双击自动调整。筛选/冻结尚不持久化，复制不等于 Excel 完整剪贴板语义。
- [x] **BASE-07 主网格稳定性修复**：FastGrid 主网格迁移和近期专项修复已接入；横向拖动整桌面停顿于 2026-10-30 经用户确认解决。真实 IME/DPI/完整辅助功能仍单独验收，见 [24](24-main-grid-migration.md)。

当前关键缺口：编辑一个普通 XLSX 后，未建模的样式关系、视图、页面/文档属性等仍可能触发另存损失提示；数据验证、条件格式、Excel Table、图表和透视表尚无完整语义支持。未知/数组/结构化公式也不能视作可重算。先补这些文件互通与日常操作断点。

## 3. 阶段总览

| 阶段 | 优先级 | 交付目标 | 进入 / 退出条件 |
| --- | --- | --- | --- |
| E0 基线与兼容诊断 | P0，立即开始 | 可追踪的特性矩阵、样本和读改存比较工具 | 先覆盖 E1 所需特性即可推进，不等待收集所有 Excel 功能 |
| E1 常见 XLSX 保真 | P0/P1 | 常见模板显示正确，小改后能保住已支持格式与元数据 | E0 的相关样本齐备；完成声明范围的 Excel→QuickExcel→Excel 往返 |
| E2 高频编辑与公式 | P1 | 完成台账、报价、汇总的日常操作 | 复用 E0/E1；新增命令原子撤销，公式与 Excel 固定结果逐项对照 |
| E3 结构化数据与录入规则 | P1/P2 | 表格对象、筛选持久化、验证和条件格式可用 | 依赖稳定引用/样式/元数据；结构变化、撤销、保存重开一致 |
| E4 报表与交付 | P1/P2 | 打印/PDF、常见图表和图片、保护与容量改进 | 依赖 E1 布局/保存；图表等按需依赖 E3 数据模型，支持子集有视觉和文件验收 |
| E5 高复杂度分析 | P2/P3 | 动态数组、基础透视表、扩展兼容 | 在真实样本价值明确后逐项推进，不作为 E1–E3 交付前置 |

E1 是当前首个产品交付目标。E2 中不依赖未完成模型的低成本项可在 E0 基线建立后穿插，但不挤占 E1 的保真修复。各阶段可按已完成子集发布预览；不要求 E5 全部完成才提供改进版，也不绕过 Beta 原有门禁。

阶段表达主要依赖和交付批次，不是必须整批串行等待的锁。P0 优先约束相关路径的正确性；E2 的计算/导出语义与对应函数同步验证。打印虽安排在 E4，但可在 E1 页面模型稳定后提前做独立切片，不要求先完成全部 Table 或条件格式。

**完成条件**：报价、条件汇总、跨表查找与日期台账样本在 QuickExcel 和目标 Excel 版本中逐格对照；每个新增函数及参数模式独立登记。编辑→撤销→重做→保存→重开结果一致；新增函数覆盖率按支持矩阵统计，不用函数数量代替语义正确性。

## 7. E3：结构化数据、筛选与录入规则

- [ ] **XC-0301 AutoFilter / sortState 持久化**（P1｜I4/F5｜L）：将已有会话筛选/排序设置与 XLSX/XLSQ 模型对接，保留多列条件及排序状态，区分手动隐藏与筛选隐藏。超出当前筛选能力的条件先保留/报告，不能改写为不同条件。
- [ ] **XC-0302 Excel Table 基础**（P1｜I5/F4｜L）：表范围、表头、名称、样式/隔行底色、筛选及汇总行的 R/D/W；普通单元格编辑和表边界变化不得破坏关系。先做受限编辑，结构化公式未支持时按 XC-0106 保留/限制。
- [ ] **XC-0303 结构化引用与表编辑**（P1｜I5/F4｜XL）：表/列引用语法、当前行、计算列、扩展范围、重命名与插删联动；在 XC-0302 和稳定依赖索引上实现，跨表/复制/撤销均需对照，不用字符串替换公式。
- [ ] **XC-0304 数据验证**（P1｜I4/F4｜L）：列表/范围列表、整数/小数/日期/长度及基础自定义公式；读显写、输入提示/错误提示、粘贴和批量编辑的处理规则一致。首期不支持的验证类型保留并报告，不能静默撤销原限制。
- [ ] **XC-0305 条件格式基础**（P1｜I4/F4｜L）：单元格比较、简单表达式、重复值及文本规则；处理优先级、stopIfTrue 和差异样式，增量刷新与引用变换一致。色阶/数据条/图标集分为后续子切片，不在基础规则完成时一并勾选。
- [ ] **XC-0306 常用清洗命令**（P1｜I4/F4｜M）：删除重复项、分列（分隔符/固定宽度）、文本数字转换的显式选择；预览后原子提交，保留文本 ID、前导零和日期解释，失败不留下部分修改。
- [ ] **XC-0307 分组与分类汇总**（P2｜I3/F3｜L）：行列 outline 分组/折叠的导入显示保存，SUBTOTAL 的筛选/手动隐藏语义；分类汇总生成命令依赖公式和结构变换，分开验收。

**完成条件**：含 Table、验证、条件格式和筛选的样本往返后，Excel 中规则仍有效；在 QuickExcel 中编辑、排序、插行、撤销不能留下过期引用或错误隐藏状态。Table 实现不能只保留视觉条纹。

## 8. E4：报表、打印与交付能力

- [ ] **XC-0401 打印预览与打印/PDF**（P1｜I4/F4｜L）：基于 XC-0105 的页面元数据实现分页、重复标题、打印区域、页眉页脚、缩放适页和系统打印/PDF；先覆盖普通表格、合并与基础图片，跨 DPI 的分页和裁剪需视觉验收。
- [ ] **XC-0402 图片锚点与操作**（P2｜I4/F3｜L）：在现有 twoCellAnchor 子集上增加像素偏移、常见 oneCell/absolute 锚点、移动缩放和跟随单元格规则；裁剪/旋转单列，插删行列、保存重开不会漂移。
- [ ] **XC-0403 常见图表子集**（P2｜I4/F3｜XL）：先读显写柱形/折线/饼图，再提供简单插入和数据范围编辑；轴/图例/系列/缓存与来源引用一致。其他图表先保留/报告，改了源数据后不能将旧图形冒充最新结果。
- [ ] **XC-0404 工作表保护与批注编辑**（P2｜I4/F3｜L）：读写并遵守锁定/允许操作的工作表保护，提供传统批注编辑；线程评论另列。工作表保护是操作约束，不宣传为加密安全，文件密码加密不属于此切片。
- [ ] **XC-0405 容量与大文件能力分级**（P2｜I4/F3｜XL）：按实际样本分级提升可见列、行/列坐标、样式、稀疏范围及导入预算，先测内存/取消/历史成本再放宽。无需一次达到 Excel 全上限，也不得只提高常量；每级公开准确拒绝边界。

**完成条件**：报表在 QuickExcel、导出的 XLSX 和打印/PDF 中内容、分页和支持对象一致；保存后 Excel 不修复包。每个容量级别附固定负载与原始性能数据。

## 9. E5：高级分析与扩展兼容

- [ ] **XC-0501 动态数组基础**（P2｜I4/F3｜XL）：溢出区域所有权、阻塞/错误、数组值、依赖与结构变换；再接入 FILTER/SORT/UNIQUE/SEQUENCE 和查找函数数组返回。先完整落地数组模型，不逐函数硬编码溢出行为。
- [ ] **XC-0502 基础透视表**（P2｜I4/F3｜XL）：先验证定义/缓存可保留并显示已有结果，再实现基于本地表数据的创建/刷新/行列字段/求和计数。源数据变更但尚不能刷新时明确过期；切片器/数据模型另行评估。
- [ ] **XC-0503 更复杂公式体系**（P3｜I3/F2｜XL）：按样本需求评估 LET/LAMBDA、OFFSET/INDIRECT、旧 CSE 数组、3D/联合/交叉引用及更多财务/统计函数；逐项定义依赖和重算成本，不把整组一次标记支持。
- [ ] **XC-0504 扩展文件变体与对象**（P3｜I3/F2｜XL）：盘点 Strict OOXML、更多绘图、线程评论和外部链接保留需求，逐项确定投入；外部数据默认不刷新，无法证明安全保留时继续报告/拒绝。此项完成要求拆出有明确验收的小项，不能以调查完成充当实现完成。

VBA/XLSM 执行、Power Query/Power Pivot 引擎、插件、云协作、任意外部数据自动刷新和旧 XLS 二进制格式暂不进入本工程交付承诺。图表/透视表的受支持子集已进入后续阶段，更新旧产品范围中一概延期的描述；完整 Excel 克隆不是验收标准。

## 10. 实现与验收规则

1. **仓库边界**：全部普通任务在 QuickExcel 内实现。Core 保持纯 .NET；类型/命令在 Core，XLSX 适配与计算在 Infrastructure，UI 只投影与提交。ExcelIO 是独立只读源码依赖；需要库变更时先拆出单独任务，不在本工程顺带改库。
2. **保存安全**：从不可变快照准备完整变更与输出，原子提交、一次撤销；未知部件只有依赖有效性被证明时才保留。改坏引用、删除未知特性或跳过内容不能当作兼容改进。
3. **格式契约**：视图/筛选/验证/Table 等新增元数据须定义 XLSQ 版本与必需能力策略，验证旧读取器行为；不能仅在控件内保存状态。保留已支持的 v1 回归与原文件保护。
4. **对照证据**：读取/写回比较包含包结构、语义和需要时的像素；公式使用目标 Excel 生成的固定期望，并记录版本、文化、计算模式。视觉差异使用明确容差，计算正确性不靠截图判断。
5. **测试范围**：代码变更只运行相关规则/存储/计算测试及 WPF 专项；基准单独运行，保留原始样本。所有 managed 命令指定 `--artifacts-path`。阶段发布再统一执行相关集成与包验收，不为每项功能反复跑全量。
6. **完成记录**：勾选时记录提交、支持维度、适用子集、相关测试、真实 Excel 版本/结果、证据路径和剩余限制；原本“部分”的任务只有本条范围全部达成才勾选。不可用功能不增加可点击占位按钮。

建议每项关闭记录采用：`ID / 日期 / 提交 / R-D-C-E-W / 夹具与结果 / Excel 对照 / artifacts 路径 / 限制`。任何已交付能力回退时取消相应勾选并关联回归，不改写历史通过证据。

当前 QuickExcel 的坐标/容量仍沿用现有预算；Excel 的工作表上限为 1,048,576 行、16,384 列，这只是对照值，不是本阶段的容量承诺，见 [Microsoft Excel 规格与限制](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits)。

## 11. 首轮可执行切片与原里程碑安排

**首轮顺序：XC-0001/0002 → XC-0003 → XC-0101/0102/0103。** 先用普通 Excel 生成的样式/金额/日期/元数据夹具定位当前兼容报告和往返差异，再做数字格式、样式继承及安全保留；以“普通模板改一个值后仍能交回 Excel”为首个结果。XC-0104/0105 随该保存模型补齐视图和打印配置，XC-0106 单独处理公式风险，避免互相掩盖失败。

本工程当前优先于新增脚本能力、独立自动恢复功能和发布包装扩展。M5 的 IME/键盘/辅助功能检查随触及的界面推进；已发现的数据损坏、权限或崩溃回归始终及时修复。M4 严格策略/部署、M6 自动恢复和最终 OS/性能/干净机器验收保留为后续必做，未通过前不宣布 Beta。阶段内不因本计划而扩大脚本权限。
