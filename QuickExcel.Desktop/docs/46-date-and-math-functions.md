# XC-0207：日期、数学与工作日公式

2026-10-30 完成声明范围，含同组 WORKDAY/NETWORKDAYS 子切片。17 个函数接入内置登记、类型化计算、公式补全/参数提示、普通公式保存、一次撤销和增量重算。单元格仍保存 Number/Text/Boolean/Blank/Error，日期解释沿用工作簿 1900/1904 系统，不改变输入类型。

## 范围与边界

| 函数 | 已固定行为 |
| --- | --- |
| DATE | 年/月/日向下取整；0–1899 年加 1900；允许月份、天数进退并验证最终日期。1900-02-29 为序列 60，1900-01-00 为 0 |
| YEAR / MONTH / DAY | 当前日期系统；按 Excel 的秒级舍入处理午夜附近小数。1900 序列 0 为 1900/1/0，60 为 1900/2/29 |
| TIME | 三个分量向下取整，允许相互抵消的负分量；总秒数须非负，超过一天取小数部分；各分量限有符号 16 位范围 |
| HOUR / MINUTE / SECOND | 以秒舍入后取 24 小时时间分量；日期上界的舍入溢出返回 `#NUM!` |
| EDATE / EOMONTH | 月数向零截断；按目标月真实公历天数截断日号。EDATE(60,0) 和 EOMONTH(60,0) 在 1900 系统均为 59，不生成虚构月末 |
| WEEKDAY | 默认 1，支持 1/2/3 和 11–17；小数 return_type 向下取整；保留 Excel 对 1900 前两月的星期偏差 |
| ROUNDUP / ROUNDDOWN | 位数向零截断；分别远离零/朝向零，支持负位数、大正位数及溢出；处理十进制 15 位有效数字后的浮点尾差 |
| INT | 15 位有效数字后向负无穷取整，负数与截断不同 |
| MOD | 结果与除数同号；零除数 `#DIV/0!`；浮点余数保留，商绝对值达到本机 Excel 的 1,125,900,000,000 上界时 `#NUM!` |
| WORKDAY | 排除周六、周日和节假日，天数向下取整；正/负方向、重复节假日和起始周末均固定；0 天返回截断后的起点且不求值节假日 |
| NETWORKDAYS | 包含起止日期，排除周末及节假日，起止倒序返回负计数 |

DATE 保留实测旧参数边界：month 为 -32767…32766；day 超出 -32768…32767 后按 Excel 的 32767 哨兵值处理。日期负序列与上界按具体函数校验，不能用 .NET DateTime 的负扩展直接替代 Excel 函数规则。

普通数值参数支持真空白、布尔及点号数字文本的明确转换；EDATE/EOMONTH/WORKDAY/NETWORKDAYS 的分析参数拒绝布尔。错误保留其种类。日期文本仅支持年在前的 `yyyy-M-d` / `yyyy/M/d`、可选 24 小时时间，以及独立 `H:m[:s[.fraction]]`；空文本、歧义地区日期及其他未支持日期拼写给出 `#VALUE!`。1900 系统允许明确的虚构闰日文本。未根据机器当前文化猜测月/日顺序。

1904 系统中，Excel 旧分析函数对直接文本和引用文本有不同转换。本项通过真实 Excel 固定该差异，而非统一“修正”：例如 EDATE("2024-02-29",0) 与引用一个同内容文本单元格的结果不同；WORKDAY 的标量/多格文本节假日又有区别。分析函数按 Windows 序列处理中间值后减 1462；EDATE/EOMONTH 可由合法起点返回 1904 年以前的负序列，WORKDAY 的 1904 上界较普通日期函数更低。直接/引用、数值/文本、单格/多格均有独立测试。

节假日支持标量、直接/名称区域、跨表及整列，按整数日期去重，不重复扣除周末。真空白忽略；数字文本和年在前的日期文本按声明转换，布尔/坏文本和错误不会静默丢弃。稀疏遍历只读取实际存储单元格；整周计数及二分查找避免按请求天数逐日扫描，仍检查取消和既有计算预算。

多格日期/数学数组参数、IF 等生成多格节假日引用尚未实现，绑定时拒绝，导入走整簿只读/Blocked 缓存/原包保存。直接节假日区域可多格，返回标量的 SUM 等表达式保持标量能力；未开放动态数组。WORKDAY.INTL/NETWORKDAYS.INTL 不属于本项。

微软的 [WORKDAY 文档](https://support.microsoft.com/en-us/excel/functions/workday-function)说明工作日及节假日语义，[MOD 文档](https://support.microsoft.com/en-us/excel/functions/mod-function)说明除数符号与零除错误。精确的舍入、旧分析函数文化差异和数字边界以独立 Excel 实验为准。
